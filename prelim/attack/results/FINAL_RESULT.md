## 何が改善したか

MIA CSVはv4とバイト単位で同一で、今回のMIA全体・希少・AUC・対象別バンドも
v4の報告値と完全一致した。改善はAIAによる。

得点済み13対象は、過去の対象別最高値を出した**対象全体326行**の提出ブロックを
再利用した。今回の13対象の得点は、保存済み各コピー元の実測値と全て一致した。
ブロックの同一性は生成器と同じpandas数値解釈での照合を指す。CSVの読書きにより
時刻の最終桁が丸められる例があり、AIAのバイト同一性を意味しない。
未得点7対象にはv7の戦略を残し、そのうち次の5対象が新たに正の得点を得た。

## 集約値と表示丸めの照合

合計に入るAIA力は、20対象の `aia_per_target` の平均である。
`score_4 + score_5` ではない。MIAも対象ごとの全体・希少の最大値を集約するため、
表示されたMIA全体・希少の値だけから正確なMIA合計を再構成することはできない。

```text
得点済み13対象のAIA寄与（以前の条件付きAIA下限） = 0.1506204125415067
旧未得点7対象の今回のAIA寄与                    = 0.032124655148639644
今回のAIA力 = mean(20対象)                       = 0.18274506769014637

前回v6のAIA力                                  = 0.14248115204199743
13対象の過去最高ブロックへの復元による差          = 0.008139260499509277
旧未得点7対象による差                            = 0.032124655148639644
AIA力の合計差                                   = 0.04026391564814894
```

以前のv4 MIA推定中心値は、独立AIA probeの丸め済み合計から差し引いた
`0.1579114879230253 ± 0.00005`。これに今回の正確なAIA力を足すと
`0.34065655561317165` となり、4桁表示の **0.3407** と整合する。
逆に今回の表示合計から引くとMIA推定中心値は `0.15795493230985364` になるが、
差 `0.00004344438682834` は表示丸めの範囲内であり、MIAが強化された証拠ではない。
以前の条件付き総合下限約0.30848を上回った分は、旧未得点対象の今回の正の寄与で
説明できる。下限そのものを事前予測や実測値へ読み替えない。
