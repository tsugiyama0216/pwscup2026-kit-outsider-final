## 読むときの注意

- MIA・AIAの一般的な基礎説明は省き、初期v1の実装に絞っています。
- MIAの提出値は所属確率ではなく、対象ごとの順位です。
- 資料中のAIA非選択行の `0.0` 年は当時の競技上の退避回答です。最終v9のv7由来部分で使う `9.5`・`11.0` などとは異なり、現在の回答値として流用しないでください。
- 配布された競技データを使う、認可済みのローカル統計分析を扱っています。サーバーへの攻撃や、現実の個人特定を目的とした資料ではありません。
