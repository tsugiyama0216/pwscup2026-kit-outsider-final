# 設定ファイル置き場

ここには、PWSCUP向けAIM合成器で使用する公開設定だけを置きます。

- 公開スキーマから決めた列型・カテゴリ全集合
- 数値列と生存時間の固定ビン境界
- AIMに渡すworkloadと重み
- 隣接関係、総プライバシー予算、予算配分

秘密データから非DPで推定したmin/max、カテゴリ、ビン境界は保存しません。
`pwscup_aim_v4.json` が現在の既定実行設定です。v1〜v3は比較用として残しています。
主な内容は次のとおりです。

- 1人1行の追加・削除隣接関係、総予算 `rho = 0.1`（zCDP）
- 公開 `schema.json` と公開背景データ `A_bg.csv` だけで固定したカテゴリ・ビン境界
- 発症・死亡・打ち切りと時間帯をまとめた `outcome_state`
- Cox解析で使う9変数と `outcome_state` の固定測定後、残りをAIMで適応測定
- 公開された希少群検出器から行単位で作る補助変数 `rare_flag`
- DP合成後の検出希少行を、公開`A_bg.csv`の希少行から7変数まとめて復号する後処理
- 公開`A_bg.csv`だけから固定した発症・死亡Coxリスク空間でDP合成共変量の最近傍を求め、
  `time`、`onset`、`death`を同じ公開行から移植するv3後処理
- 公開`A_bg.csv`の希少率から目標件数を決め、DP出力のMahalanobis距離上位行を
  `4 <= 距離 < 5.5`の公開ドナーで復号するv4後処理
- 目標外で検出された希少行を、公開`A_bg.csv`の閾値直下の非希少行で修復するv4後処理

v2〜v4の固定seedは公開希少ドナー選択だけに使います。OpenDPのDP測定乱数は
固定しません。v3のCox係数と死亡リスク重み`0.25`は練習段階で設定に固定し、最近傍転帰
選択は決定的に行います。いずれもDP測定後の公開データ後処理です。

v4の公開ドナー範囲とseedも練習段階の比較後に設定へ固定しています。保護対象となる
本番入力を見て再調整せず、この固定アルゴリズムを適用してください。

設定を変更すると、同じ入力でもプライバシー予算の配分と有用性が変わります。
