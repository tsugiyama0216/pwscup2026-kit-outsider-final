## 採用方法

1. **地域件数の補正**。都道府県の件数をBの集計件数に合わせる。過剰な地域の合成行を不足地域へ再配分し、変更は58行。割当ての費用にはBの地域別群重心を使い、全体平均10件分への縮小で小集団の不安定さを抑える。Bの個別行との対応は作らない。
2. **年齢分布の補正**。配布schemaで検出される希少群・多数派別に、Bの年齢の経験分位点へ写して整数化する。年齢変更時に検査値6項目を集団中心からの方向に沿って微調整し、各行のマハラノビス距離を保持する。332行の年齢が変わり、値域・幾何条件を満たさない2行は元のままにした。希少区分は変えない。
3. **集計制約による同時補正**。BMI・SBP・log(TG)・HDL・log(ALT)・FPGの6列を変数とし、Bの集計Cox係数におけるEfronスコア、推定標準誤差、順位相関、全体と希少群の分位点を合わせる。地域等との関係が過度に強くなることと、R8から大きく離れることにも罰則を置く。元Bの特定人物に合成行を近づける目的関数は使わない。
4. **制約と再検算**。公式の生理的値域と、前処理後の各合成行からB標準偏差1個分以内という移動範囲を設定する。希少区分を変える移動には強い罰則を置き、必要なら元の合成行との線分上で区分を復元する。採用候補では最終的な区分復元は0行だった。最終CSVを公式コードで再採点する。

自動微分とL-BFGS-Bを用い、6,294変数を300反復で補正する。採用した重みは、全体分位点10、希少分位点4、順位相関300、標準誤差100、希少区分10,000、群関係100、移動量0.02。Efronスコア項は9係数で正規化して重み1。CDFを補間した相関を最適化に用い、実際の順位相関は公式採点で確認する。

最適化は事前に決めた300反復で終了しており、数値最適化の完全収束・大域最適解を主張しない。reportのoptimizer_success=falseは反復上限到達を表す。有限な改善解であること、公式提出形式と得点を別途検証して採用した。

R8の各行の時刻・発症・死亡の組、性別、喫煙状態を保持する。全体の発症110・死亡71・打切り868も変えない。前処理後の年齢・都道府県は最適化中は固定する。R9では追加の事象交換を行わない。

## 比較と選択

各4候補、計12設定を3段階で比較した。最初の同時補正はCox解析を改善したが、検出希少件数が減ったため不採用。次に地域件数と希少区分を保護してU約0.986まで改善した。残る希少年齢分布の差を補正した最終段階で0.99を超えた。

各段階の設定は実行前に固定したが、段階間では直前の結果を受けて方法を変更した。乱数種・行順の探索は行わず、同じ入力と設定から決定的に生成する。全比較記録はinitial_summary.json、constraints_summary.json、age_summary.jsonに保存した。候補のCSVハッシュと最終生成物も一致を要求する。

同じ評価データによる選択なので、独立ホールドアウト評価ではない。生成入力はteam10のB、固定R8、配布schema。B_selfの真の希少ラベル、A_bg、utility_refは評価・候補選択だけに使う。
