## 生成方法

1. **検査値:** R1と同じ性別×喫煙の4群で、年齢・BMI・SBP・TG・HDL・ALT・FPGをガウシアン・コピュラで合成。相関は3%縮小。年齢は離散分位点、他は連続分位点を使う。各群人数を保持し、都道府県は群内頻度に全体頻度5件分を加えて別途生成する。
2. **Cox学習:** B全体について発症と死亡それぞれの原因別Coxを推定する。9変数は年齢・性別・BMI・SBP・log(TG)・HDL・log(ALT)・FPG・喫煙。原則は無正則化であり、収束失敗時だけ事前固定の小さいridge値から順に試し、使用値を記録する。
3. **時間分布:** 観測期間10年を事前固定の40区間に分け、各区間の発症・死亡件数を保持する。区間内では新しい等間隔時刻を作り、両原因を固定乱数で配置する。個別のBの事象時刻は直接コピーしない。
4. **人物への割当て:** 時間順に、まだ事象が起きていない合成人物からCoxリスクexp(βx)に比例して1人を選び、その事象を割り当てる。割当て済み行はリスク集合から除く。これにより発症110件・死亡71件・行政打切り868件を保持する。
5. **完成:** 残りの観測時刻を10年にそろえ、行をシャッフルして13列に固定する。Bの行政打切りは日単位丸めによって10年より0.5日短いため、学習では原本時刻を保持し、出力だけ10年に正規化する。

seedはR1と同じ`20260917`で固定し、seed探索はしていない。学習入力はB.csvのみ。B_selfの真の希少ラベル、A_bg、utility_ref、希少検出参照は生成後の評価専用である。これはR2の設計判断であり、「規則がBのみ学習を強制する」という意味ではない。

全係数を用いた最大8回の集計較正も比較したが、U=0.766542で補正なしを上回らなかったため採用していない。提出用R2は`CALIBRATION_STEPS=0`。不採用実験もlocal-outputに保存した。
