## 変更した加工

1. SHA-256で固定したR2/C.csvを読み込む。R2自体の再生成は行わない。
2. BとR2について、年齢・性別・BMI・SBP・log(TG)・HDL・log(ALT)・FPG・喫煙の全9変数で、無正則化の発症Coxを推定する。
3. 係数差を小さくするよう、BMI・SBP・log(TG)・HDL・log(ALT)・FPGの6変数を連続的に補正する。Bから推定した共分散を計量とし、3%の対角縮小で安定化する。**補正強度は0.5で固定**。
4. TG・ALTを元スケールに戻して、公式値域を確認する。採用したR3はクリッピング0件。年齢・性別・喫煙・都道府県・事象・時刻はR2の値を保持する。

発症110件、死亡71件、行政打切り868件を保持する。個々の元B行を合成行へ対応させず、係数と共分散という集計統計を使う。検査値の変位のRMSはBの標準偏差の約1.1〜5.5%である。

数式では、特徴行列X、Bの係数β_B、R2の係数β_Cに対して、連続変数への変位を `0.5 × (X−mean(X))(β_C−β_B)Vᵀ` とする。`Vᵀβ_B=1`を満たす共分散計量の方向Vを選ぶ。年齢・カテゴリは直接変更しないが、全9係数の差を補正に反映する。完全補正は係数を近づけても標準誤差まで一致させるものではないため、候補比較では部分補正を採用した。

学習入力はteam10のBと保存済みR2の合成データ。B_selfの希少真値・A_bg・utility_refは生成後の候補評価専用。6候補からローカル有用性で選択したことを記録しており、評価情報と無関係に設定を決めたとは主張しない。
