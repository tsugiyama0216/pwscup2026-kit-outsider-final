# R12 本戦ルール対応

2026-09-19、[公式大会ページ](https://www.iwsec.org/pws/2026/cup26.html)の本戦正本 `main-process-20260912` を確認。
保存済みPDFの§5.1、§5.3–5.4、§7.4–7.5を再確認した。
固定公式キットのコミット、採点設定、ルールブック、配布原本6ファイルを実行時に照合する。

| 根拠 | R12の対応 |
|---|---|
| §4 加工対象 | 自チームBに由来する凍結R11を学習した派生合成データ。新たな他チームBや非公開外部データは使わない。 |
| §5.1 単一表・点値・値域 | 1,049行・指定13列、欠損なし、record_idなし、全値が許容範囲。公式検証器を使用。 |
| §5.3–5.4 自己採点 | 未変更の公式キットで計12候補を比較し、ローカル有用性UとR11公式有用性以上を採用条件とする。同じデータによる選択を明記。 |
| §5.5 ZIP | ZIP直下にC.csvと配布原本token.txtのみ。公式検証、CRC、CSV・tokenの原本一致、再読込採点を確認。 |
| §6.1 有用性 | 希少56行、全行の固定7列、希少区分を保持。Cの完全重複とBとの完全一致行は0。U_spec単独は低下するが最小値Uは維持。 |
| §6.2 匿名性 | 参照攻撃AUCを高める処理・選択はしない。R11の公式MIA=0やAUCをR12の測定値として流用しない。 |
| §7.4–7.5 監査・生成AI | 生成手順、R11来歴、比較候補、保存モデル、検証ハッシュを保存。許可された非公開リポジトリのみへ保存し、トークンはログ・文書に出さない。 |

経験コピュラの順位表・固定列・希少値・境界例外は、実在の元B行ではなくR11の合成行に由来する。
元Bの行との新たな対応付けは行わないが、R11の生成来歴や潜在的な情報漏洩を消す処理でもない。
本手法はR11の生成部分を簡略化するもので、独立したゼロからの単純学習や形式的なプライバシー保証は主張しない。
公式最終総合得点の非低下は未確認。CodaBench送信・公式試行の消費は行わない。
