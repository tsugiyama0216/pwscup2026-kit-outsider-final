# R4: 発症リスクを保つ検査値の同時分布補正

2026-09-17作成。R3の合成データに、年齢・性別・喫煙で条件付けた検査値の分布補正を加える。補正から発症Coxのリスクを変える成分を取り除き、R3の解析結果を保ちながら一般分布と希少群の再現を改善した。

**ローカル有用性U=0.8683850877951735。** R3の公式結果としてユーザーが提示した0.8661244917109793から、0.002260596（約0.26%）の小幅改善。一般有用性も0.918788から0.931917へ改善した。4指標はすべてR3と同等以上だが、R4の公式結果・攻撃耐性は未取得である。

## 加工方法

1. SHA-256で固定したR3/C.csvを読み込む。R1〜R3を再生成・変更しない。
2. BとR3それぞれのBMI・SBP・log(TG)・HDL・log(ALT)・FPGを、年齢・性別・喫煙へ線形回帰する。Bの標準偏差で単位をそろえる。
3. 合成データの条件付き平均と残差共分散をBへ近づける変位を、ガウス分布間の共分散変換で計算する。
4. その変位をR3の発症Cox係数に直交する方向へ射影し、各合成人物のCox線形予測子が変わらないようにする。**補正強度は0.5**で固定する。追加のCox係数補正はしない。
5. TG・ALTを元スケールに戻して値域を検査する。R4ではクリッピング0件。年齢・性別・喫煙・都道府県・事象・時刻はR3から変更しない。

発症110件、死亡71件、行政打切り868件を保持する。元Bの個人行との対応付けは行わず、回帰係数と共分散などの集計統計を利用する。希少真値や公式検出器の閾値を使って、特定の行だけを直接調整する処理は行わない。

補正関数の入力はBと保存済みR3のCSV。B_selfの希少真値、A_bg、utility_refは生成後の候補評価に使用する。22候補から同じローカル評価で設定を選択したため、独立した汎化評価ではない。詳細はEXPERIMENTS.mdを参照。

## 限界

Uの改善幅0.0023は小さく、U_rareの環境差や少人数の評価変動の影響を受ける。公式環境での改善を保証する値ではない。R3の参照MIA=0、AUC=0.5171484375はR3だけの観測値であり、R4へ流用しない。R4の参照MIA・公式保護指標は未評価で、差分プライバシーの保証はない。
