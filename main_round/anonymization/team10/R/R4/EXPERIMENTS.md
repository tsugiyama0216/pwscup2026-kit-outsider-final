# R4の比較実験

2026-09-17。本戦team10、固定されたR3のC.csv、同じ本戦キットで計22候補を比較した。乱数種・行順を変更して得点を探す処理は使わない。

## 比較した加工

1. 周辺分布の補正8候補: 全体または性別内で、6検査値をBの同じ分位点へ25%・50%・75%・100%近づけた。希少群の同時分布指標が低下し、不採用。
2. 条件付き同時分布の補正6候補: 年齢・性別・喫煙への回帰と、残差共分散をBに近づけた。強度25%・50%・75%、Cox再補正なし/25%を比較。一般分布は改善するがCox係数が動いた。
3. 発症リスク保持4候補: 2の変位からR3のCoxリスクを変える成分を取り除き、強度25%・50%・75%・100%を比較した。
4. 周辺探索4候補: 3で最も良かった50%の前後、40%・45%・55%・60%を比較した。

各段階の候補は、その段階を実行する前にスクリプトに固定した。全22候補を最初から一括して事前指定したわけではない。補正にはBとR3だけを使用し、候補選択にはB_self・A_bg・utility_refを含む公式ローカル評価を使った。

R3に対するUの上昇は0.002260596（約0.26%）と小さい。一般有用性は0.013129改善、希少プロフィールは0.866124から0.889006へ改善した一方、希少C2STは0.913396から0.868385へ下がり、R4の最小指標になった。4つの大項目がすべて同等以上でも、内部の全指標が改善したわけではない。

希少群が少人数であるため、C2STは候補間で大きく変わった。選択に同じローカル評価を使っており、独立な汎化評価ではない。本戦ルールにもU_rareの環境差が約0.01となり得る旨があり、0.0023の上昇が公式環境で必ず得られるとは保証しない。

詳細CSV・レポートはlocal-output/に保存し、集計はexperiment_summary.jsonに保存した。research.py、research_joint.py、research_projected.py、research_refined.pyは既存ラベルを上書きせず停止する。再実行は実験出力がない作業コピーで行う。

R3の参照MIA=0をR4の値として流用しない。R4の公式攻撃耐性は未評価で、差分プライバシーの保証はない。
