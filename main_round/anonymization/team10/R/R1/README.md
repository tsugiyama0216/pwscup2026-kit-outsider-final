## 方法

1. 性別・喫煙の4群に分け、各群の7変数（年齢・BMI・SBP・TG・HDL・ALT・FPG）を順位から正規分布へ変換します。
2. 各群の相関行列を推定し、3%の縮小で安定化します。多変量正規乱数を生成して経験分布の逆関数で戻します。年齢には離散分位点を用います。群ごとの人数はBと一致させます。
3. 都道府県は同じ性別・喫煙群の頻度から別途生成します。小さい頻度の不安定さを抑えるため、全体頻度5件分を加えます。
4. Bで発症・死亡それぞれの原因別Coxモデルを学習し、新しい検査値に応じて発症時刻と死亡時刻を生成します。TG・ALTは対数変換し、L2ペナルティは0.01です。先に起きた事象を採用し、どちらも10年を超える場合は「事象なし・time=10」とします。時刻は推定累積ハザードの一般化逆関数から標本化します。
5. 行順をシャッフルし、識別子を持たない13列に固定します。元の行を選んで微小ノイズを付ける方式ではありません。

30件未満の群では性別群、さらに不足すれば全体へ学習プールを広げるフォールバックがあります。今回の4群は493・48・351・157件で、フォールバックは使っていません。

乱数種は採点前に `20260917` に固定しました。候補は1つで、採点に基づく乱数種探索は行っていません。`B_self.csv` の希少ラベル、`A_bg.csv`、`utility_ref.json` は評価専用です。推定モデルの配列や元データ行を別ファイルに保存していません。

## ローカル有用性

最終ZIPに入ったCSVを公式自己採点器へ読み込ませた結果です。

| 指標 | 値 |
| --- | ---: |
| U（4観点の最小値） | **0.564209862140604** |
| U_gen: 一般的な有用性 | 0.9356950836160121 |
| U_spec: 特定解析の有用性 | 0.564209862140604 |
| U_rare: 希少群の再現 | 0.7978218535881715 |
| U_valid: 妥当性 | 1.0 |

現在の弱点はU_specです。Cox解析でBMIと喫煙の有意性判定がBと一致せず、FPGの係数も弱くなっています。分布や希少群は比較的よく再現されていますが、解析結論を完全には保存していません。

**非重複・完全合成・U_valid=1は、匿名性を保証しません。** 経験分布や性別・喫煙別人数はBから学習しており、差分プライバシーの保証はありません。都道府県と検査値の群内依存もモデル化していません。公式の保護指標・攻撃耐性は未評価で、最終的な有用性の公式記録もCodaBench側の結果です。
