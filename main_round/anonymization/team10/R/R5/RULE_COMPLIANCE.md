# R5 本戦ルールとの対応

2026-09-18、公式大会ページが指定するmain-process-20260912版を確認。保存済みルールブックと固定公式キットのハッシュを生成時・検証時に照合する。

| 根拠 | 対応 |
|---|---|
| §4: 自チームBからCを生成 | team10のBだけで学習。先行する合成列に条件付けた生成。他チームの非公開データを不使用。 |
| §5.1: 行数・列・点値 | 元Bと同じ1,049行、指定13列。識別子・希少ラベル・欠測を含めない。型・値域・排他的イベントを公式検証。 |
| §5.3–5.4: 改善・自己採点 | 事前固定6設定を同一乱数種で比較。公式採点コードは変更せず、全候補を保存。 |
| §5.5: 提出形式 | ZIP直下C.csvと原本token.txtのみ。CSV・トークンは原本バイトとの一致を検証し、トークン値は出力しない。 |
| §6.1.2 / §6.1.4: 分析再現・妥当性 | Cox条件付きイベント生成と集計補正。行政打切り10年、発症と死亡の排他、元B完全一致行と重複行がないことを検証。 |
| §3.2 / §7.4–7.5: 秘密保持・生成AI | 認可された競技データ内で作業し、ユーザー指定の既存非公開GitHubのみへ保存。 |

B_self・A_bg・utility_refは評価と候補選択に使用する。Bのみの学習は設計上の選択であり、ルールが強制するという意味ではない。公式採点や匿名性を保証するものではない。差分プライバシーは未適用であり、R3の過去の攻撃結果をR5へ流用しない。

ユーザー依頼に基づきR5の提出ZIPを含めてPCと非公開GitHubへ保存する。大会への提出操作は実施しない。
