# R5: 逐次条件付き合成

2026-09-18作成。team10のBだけを学習入力とし、各列を既に生成した列に条件付けてCARTで逐次生成する独立の合成モデル。R1〜R4のCSVは使用しない。

## 提出ファイル

- [提出ZIP](submission/team10_R5_defense.zip): 直下にC.csvと配布原本token.txtのみ。
- [合成CSV](C.csv): 1,049行・指定13列。
- [評価・来歴](report.json)、[候補比較](experiment_summary.json)、[ルール対応](RULE_COMPLIANCE.md)。

## 方法

生成順は性別→年齢→喫煙→BMI→FPG→TG→HDL→SBP→ALT→都道府県。各列の決定木は元Bの先行列で学習し、生成済みの先行列を入力して葉を選ぶ。カテゴリと年齢は葉の経験分布から独立抽選し、連続値は葉内の経験分位点を線形補間する。TGとALTは対数空間で扱う。都道府県は文字列のカテゴリとして復元する。

採用設定は最小葉サイズ20、最大深さ7、乱数種20260918。行単位の共通ドナーを使わない。続いてR2と同じ競合リスクCoxの条件付きリスク集合抽選で発症・死亡・時間を生成し、R3と同じ集計Cox補正を強度0.5で適用する。したがって純粋な全列CARTではなく、CART逐次合成と生存時間モデルの組合せである。継承したsurvival.pyとcalibration.pyは旧モデルの保存済み成果物を変更せずコピーした。

## ローカル評価

| 指標 | R5 | R4（比較用） |
|---|---:|---:|
| U_gen | 0.9204916521 | 0.9319172595 |
| U_spec | 0.8079092631 | 0.9136141267 |
| U_rare | 0.8625840349 | 0.8683850878 |
| U_valid | 0.9992488797 | 1.0 |
| 最小値U | 0.8079092631 | 0.8683850878 |

生成前に葉サイズ20/40/60×補正強度0/0.5の6候補を固定し、公式自己採点で最大Uを選択した。希少検出46（ゲート8）、補正での範囲クリップ0。R4より有用性が低いため、性能改善版とは扱わない。U_validは軟らかい妥当性得点であり、公式スキーマの形式検証とは別である。候補選択と評価に同じローカル参照を使い、独立ホールドアウト評価はしていない。B_selfの希少ラベル・A_bg・utility_refは生成器に渡さず、評価と候補選択にだけ使う。

差分プライバシーやk匿名性の保証はなく、葉サイズ20はk匿名性を意味しない。公式攻撃耐性・公式採点は未取得。CodaBenchへは送信していない。

U_validの微減は新規性項目novel=0.9969955188による。打切り・不自然な関連の抑止・重複抑止の各項目は1.0。背景データA_bgは生成に使っていないが、公式の背景データへの接近度の統計で小さな減点となった。

## 検証・再現

リポジトリルートから `./main_round/anonymization/team10/R/R5/run.ps1 -Mode Test` で人工データを用いた条件付き依存・葉の支持数・型・識別子不使用・再現性のテストを実施する。`-Mode Verify` は提出ZIP・公式スキーマ・スコア・来歴を検証し、`-Mode Reproduce` はさらにCSV全バイト再生成一致を確認する。Generateは既存成果物の上書きを拒否する。

3テスト成功、公式提出形式・行数・値域検証成功、CSV全バイトと自己採点の再現一致を確認済み。[検証記録](verification.json)に成果物ハッシュを保存する。
