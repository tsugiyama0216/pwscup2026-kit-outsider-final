## 採用方法

1. **多数派の条件付きガウシアン・コピュラ補正、強度0.5**。配布schemaの検出基準で区分し、7連続変数の順位を正規潜在変数へ変換。性別・喫煙との関係と残差共分散をBに近づける。共分散は3%対角縮小。元R7と変換後の値を半分ずつ混ぜる。
2. **多数派の非線形分散補正**。Bと合成データのCox標準誤差の比を、BMI・SBP・log(TG)・HDL・log(ALT)・FPGの補正倍率とする。拡大時は中心からの偏差をδとして `δ + (倍率−1)δ³/(3 mean(δ²))` を用い、分布の中心への影響を抑える。縮小時は線形。これは補正倍率の目安であり、標準誤差の完全一致を保証する式ではない。
3. **区分の保護**。上の分散補正は多数派を対象とし、元から検出希少である行と、補正で新たに検出希少となる行は補正前に戻す。今回114行を保護した。提案値は公式値域へ制限するが、この値域制限の集計は保護による差し戻し前の値（reportのclipped）である。区分ごとの処理・値域制限・年齢丸めを含む最終データ全体について、順位相関の完全保存は主張しない。
4. **希少群の経験分位点を使ったコピュラ補正、強度1.0**。10%対角縮小を使う共分散変換後に再度順位を取り、B検出希少群の経験分位点へ戻す。正規CDFで戻す候補よりプロファイルが改善した。その後、各合成行の元のマハラノビス距離を値域内で保持する。範囲制限と年齢の整数化により距離・区分の完全一致ではなく、この段階の検出人数は58から56となった。
5. **合成行の事象交換**。B検出希少群の発症率23/71を目標とし、最終検出56行の発症を18件にする。Bの集計Cox係数とのずれをEfronスコアで評価し、合成発症行と打切り行の時刻・発症状態を交換する。有意係数の目標は推定標準誤差の2.02倍を下限とし、実際の有意性を最終CSVで確認。採用データでは計4回交換した。

全体の発症110・死亡71・打切り868、時刻と事象の組の分布を保持する。死亡行は事象交換の対象外。希少群発症率を合わせる段階のみ区分間で交換し、その後は同一区分内に限る。元Bの特定個体との対応付けや、個別時刻の移植は行わない。

今回の追加処理では全体の半径分布補正と希少群の半径分位点補正は無効。R7以前の生成手順は固定R7に含まれる。

## 比較と限界

9段階の候補数は順に9・6・8・6・8・6・8・8・4。全項目への線形分散補正、HDL/ALTだけの補正、希少発症率、対象区分の保護、経験分位点、値域制限、有意性の余裕、非線形補正を比較した。各段階のグリッドは実行前に固定し、段階間では前の結果を見て方法を修正した。乱数種や行順の探索は行っていない。

`select_release.py` が全候補の採用条件を再計算する。初期比較ログには恒等候補の丸め誤差を改善と判定した古いeligible値があるが、最終選択では改善幅1e-9超と全指標非低下を要求して除外する。確定した選択はexperiment_summary.jsonを参照する。

同じ評価データで多数候補を選んでおり、独立ホールドアウト評価ではない。公式環境の希少指標の変動も考慮し、公式で同じ値になることや最適値を保証しない。生成はB・固定R7・配布schemaを使用し、B_selfの真の希少ラベル、A_bg、utility_refは評価・選択にのみ使う。

R7の参照MIA=0・AUC=0.5175はR8の値ではない。R8の公式攻撃耐性は未評価で、差分プライバシーの保証はない。
