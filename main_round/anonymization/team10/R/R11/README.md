## 生成方法

R9で最も低かったのは希少群のプロファイル一致度で、0.995144だった。まずschemaで検出した合成希少56行について、検査値6項目（BMI、SBP、TG、HDL、ALT、FPG）を、自チームBの検出希少71行の経験分位点へ調整する。分位点位置は `(k+0.75)/56`、強度1.0を採用した。Bの個別行との対応付けではなく、各列の分布と合成値の順位を使う。

この分位点変換では順位を使うが、検出区分が変わる行にはR9値との線分上で区分を戻す補正を行うため、最終的な順位の完全保存は保証しない。採用候補では7行を補正した。区分を戻した後の希少56行は全列を固定し、多数派993行の6検査値、合計5,958変数をL-BFGS-Bで250反復調整する。

多数派の調整目標はBの全体分位点、順位相関、Coxスコアと標準誤差、集団間の関係である。移動はB標準偏差0.5個分以内と生理的範囲に制限し、希少区分を変える動きを抑制・修復する。重みは全体分位点10、希少分位点10、順位相関300、標準誤差100、希少区分10,000、群関係100、移動0.02。固定した希少行に関わる目的関数項は定数となる。

年齢・性別・都道府県・喫煙・追跡時間・発症・死亡は各行でR9と同じ。全体の発症110・死亡71・打切り868、検出希少56件・その発症18件も保持する。希少プロファイル較正値は0.996202となり、希少発症率較正値0.997094、希少割合1.0、C2ST較正値1.0は維持した。

最適化は250反復の上限で終了した。完全収束や大域最適性は主張せず、出力CSVの公式再採点と形式検証で採用を判断した。差分プライバシーの保証はない。

## 比較実験

1. `initial_summary.json`: 希少分位点の位置5種類×強度2種類、計10候補。分布だけの補正ではCox解析が悪化する候補があった。
2. `joint_summary.json`: 分位点の位置4種類を全体の同時補正へ組み込んだ4候補。希少プロファイルの改善が得られなかった。
3. `locked_summary.json`: 改善した希少群を固定し多数派だけを調整する2候補。両方が採用条件を満たした。

計16候補から、UがR9を超え、全ファセットがR9以上の候補を選ぶ。同じUではファセットの合計で決定し、強度1.0を採用した。[experiment_summary.json](experiment_summary.json)に選択結果と全バッチのハッシュを記録している。各バッチは実行前に固定したが、バッチ間では直前の結果を受けて方式を変更した。同じデータによる選択であり、独立ホールドアウト評価ではない。
