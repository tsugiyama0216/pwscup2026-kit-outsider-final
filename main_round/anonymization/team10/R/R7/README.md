## 採用した方法

1. **多数派の条件付きガウシアン・コピュラ補正（強度0.5）**。配布schemaのマハラノビス検出基準で多数派を区分し、7連続変数を順位から正規潜在変数に変換する。性別・喫煙への回帰と残差共分散（3%対角縮小）をBに合わせ、Bの経験分位点へ戻して元R6と50%ずつ混ぜる。
2. **外れ具合の分布補正（強度0.5）**。マハラノビス距離の分位点をBの分布へ半分近づける。生理的範囲内の半径に制限し、年齢は整数にする。行数を増減して希少件数を合わせる処理はしない。
3. **希少群のコピュラ補正（強度0.5）**。順位に基づく潜在共分散（10%対角縮小）と周辺分布を補正する。その後、各行の補正前の外れ具合を可能な範囲で保持し、希少群の人数が減りすぎることを抑える。範囲制限と年齢丸めがあるため、半径の数学的な完全一致を主張しない。
4. **合成事象の割当て補正**。Bの集計Cox係数を目標にし、Bの有意・非有意を保つよう推定標準誤差に応じて目標を調整する。Efron部分尤度のスコアのずれを減らす交換を貪欲に選ぶ。採用データでは発症行と打切り行の組を4回交換した。交換は同じ検出希少区分内に限定する。

発症時刻・発症有無の組を既存の合成行間で交換するため、発症110・死亡71・打切り868、時刻と事象の組の分布、各希少区分の発症件数を保持する。死亡行は交換対象外。元Bの特定人物と合成行を対応させず、元Bの個別時刻を移植しない。検査値の補正後に、実際の提出CSVを公式Coxコードで再解析する。

今回の最終設定では、研究用の全体共分散補正、情報行列による検査値の補正、リスク保持射影は無効。コード内に残るそれらの設定は比較実験用であり、採用モデルの処理ではない。

## 比較と選択

90設定を9段階に分けて比較した（初期の値域不適合12設定、上限による打切りを含む）。各段階の候補は実行前に固定したが、全90設定を最初に一括固定したわけではない。乱数種・行順の探索は行っていない。

強いCox補正は解析一致を高める一方で分布を崩し、不採用。多数派コピュラだけではCox再現性が低下し、不採用。事象交換で係数を近づけても有意性が変わる場合があったため、集計解析の有意性を保つ目標を用いた。希少群補正だけでは希少判定から外れる行が増えたため、半径保持を追加した。

詳細は各 `*_summary.json` と `rejected_initial_grid.json` に残す。最終選択はR6の各指標を下げない候補のうち最大U。打切り候補の未評価項目を実測値として扱わない。`select_release.py` は各段階の記録を集約する。

多数の候補を同じ評価データで選択したため、独立ホールドアウト評価ではない。本戦環境のU_rare変動もあり、公式0.95超えは保証しない。
