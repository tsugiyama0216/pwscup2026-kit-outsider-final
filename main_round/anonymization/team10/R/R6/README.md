## 合成・補正の方法

R4の保存済み合成CSVをハッシュ照合して入力する。R4は性別・喫煙別ガウシアン・コピュラで生成した検査値と競合リスクCoxの事象生成を基礎に、集計統計による補正を加えたモデルである。

R6では配布schema.jsonの検出基準（7変数のマハラノビス距離4以上）でBとR4の裾の群を取り出す。これはB_selfの真の希少ラベルではなく、配布基準で検出した群であり、Bで71行、R4で55行。

両群の年齢・BMI・SBP・TG・HDL・ALT・FPGを、列内順位から標準正規の潜在変数へ変換する。潜在共分散に10%の対角縮小を施し、R4側の依存関係をB側へ移す対称な共分散変換を求める。変換後の潜在値を正規CDFへ戻し、B検出群の経験分位点を線形補間して目標値を作る。元R4と目標値を50%ずつ混ぜ、年齢は整数へ丸める。

この方法は新しい乱数による独立生成ではなく、既存のコピュラ合成表への、裾に条件付けた追加のコピュラ変換である。元Bの特定行を合成行へ対応させる処理はない。検出群以外の994行と、全行の性別・喫煙・都道府県・追跡時間・発症・死亡は元R4のまま保持する。追加のCox補正は採用しない。

全4大項目はR4と同等以上で、Uは0.0509388125上昇した。0.9超えはローカル評価で確認しており、R6の公式採点ではない。

希少プロファイルは0.9350156077、希少C2ST較正値は1.0となった。現在の最小要素は希少割合一致mass_star=0.9193239003。検出希少数は55から49へ減少し、B検出71との差が広がった。真の希少Bは24で、検出数と同一の概念ではない。希少発症率の較正値は0.9558353511。内部項目のすべてが改善したわけではない。

事前に補正強度0.25/0.5/0.75/1.0×追加Cox強度0/0.25/0.5の12候補を固定して比較した。U_valid=1かつR4よりUが高い候補から最大Uを選択。強い補正や追加Cox補正には、有意性の変化によりU_specが低下する候補があった。全候補を保存し、乱数種・行順の探索は行っていない。

## 検証・制約

公式本戦キットを固定コミットで使用し、入力原本・ルールブックのハッシュを照合する。提出ZIPの形式、元Bと同じ行数、型・値域、イベント排他、欠測0、元B完全一致0、合成内重複0、打切り10年を確認する。発症110、死亡71、打切り868。

補正器の学習入力はB・R4・配布schemaの検出基準。B_selfの真希少ラベル、A_bg、utility_refは公式評価と候補選択に用い、補正器には渡さない。同じローカル参照で候補を選択した結果であり、独立ホールドアウトでの評価ではない。

R4の参照MIA=0、AUC=0.5176171875をR6へ流用しない。R6の公式攻撃耐性は未評価であり、差分プライバシーや匿名性の保証はない。C2ST=1は希少群の有用性指標であって匿名性の得点ではない。

リポジトリルートから `./main_round/anonymization/team10/R/R6/run.ps1 -Mode Test` で10件の人工データテストを実行できる。`-Mode Verify` は成果物・入力来歴・評価を照合する。`-Mode Reproduce` はさらにCSV全バイトの再生成一致を確認する。Generateは既存成果物の上書きを拒否する。

このPCと指定の非公開GitHubに保存する。CodaBenchへの提出は行わない。

最終検証: 10テスト成功、公式提出形式検証成功、CSV全バイト再生成一致と自己採点の一致を確認済み。R1〜R5の追跡ファイルは変更なし。検証記録にCSV・ZIP・レポートのSHA-256を保存した。
