# Rv2からの追加改善案

以下は未実装の研究案です。今回完成させた6版と混同しないでください。新採点の独立確認データが用意されてから試す順序を決めます。

| 案 | 狙い | 確認すべき失敗条件 |
|---|---|---|
| 背景との分類器密度比 | 距離では捉えにくいCの多変量特徴 | C対背景識別が個人メンバー識別にならない場合 |
| 背景の交差適合 | 分類器・密度推定の過適合を抑える | 同じ人・同じ加工世界の分割間混入 |
| 条件付き残差のMIA | 年齢・性別から予想外の検査値組合せを重視 | 予測器の残差が加工歪みを増幅する場合 |
| 希少性別の順位校正 | 希少な正常値と本当の漏洩信号を分ける | 真の希少ラベルと公開近似の不一致、少数例過適合 |
| 相互最近傍・対応の重複抑制 | 1件のCへの大量誤対応を抑える | 複製や合成データに一対一制約を押し付ける場合 |
| レコードリンケージの距離学習 | 加工されやすい属性の重みを学習 | 既知加工方式に依存して未知加工へ転移しない場合 |
| 属性の部分集合アンサンブル | 一部属性の強いノイズに耐える | 似た人が多い低次元空間で誤検出が増える場合 |
| 加工特性からの弱い方式混合 | Cの離散化・丸め・分散変化へ適応 | 特性判定ミス、対象ID暗記、ルーター不連続 |
| 時刻の単調変換・丸め推定 | 一律の時間変換を補正 | 実時刻分布差を変換と誤認する場合 |
| 検閲とイベント型を考慮する時刻分布 | 時刻上限付近の集中と発症時刻を区別 | AIAで観測できない属性の漏洩利用 |
| 条件付き密度ネットワーク/分位点分布 | 多峰性・歪んだ時刻分布を柔軟に表現 | 小標本での不安定さと計算負荷 |
| ブートストラップの順位安定性 | 下位尾部や不安定な追加信号を抑える | 真の少数メンバー信号まで平滑化する場合 |
| 条件別の安全な棄権 | AIAの背景との差がない部分の過信を避ける | 棄権の規則・floor・希少層補正への悪影響 |
| 複数候補のスタッキング | 新採点で有効な相補性を学習 | 同じ評価セットで重み調整と最終報告をする場合 |

現段階では、過去に高い模擬点が公式に転移しなかった問題を重視します。新しい複雑なモデルを増やすこと自体を進歩とはみなさず、Rv6〜Rv11の独立比較でどの信号が役立つかを先に確認します。
