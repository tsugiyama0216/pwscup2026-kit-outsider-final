## 採用した変更

MIAはRv2の順位を基礎に、7連続属性の最近傍距離を公開背景と比較します。加工Cのほうが背景より十分近い候補だけ加点します。弱い距離情報を全件混合する候補は調整結果で不採用でした。自己の公開問題から厳密に特定できる非共有163人は引き続き0です。対象番号ごとの特別扱いはありません。

AIAはRv2を基礎に、Cへの最近傍距離が背景への距離の10%未満で、5近傍の時刻窓の支持率が60%以上のときだけ補正します。時刻は近傍の±0.5年窓から選びます。弱い一致を広く使う補正と一律の棄権は不採用でした。

`selection.json` に数値ソースのハッシュを固定してから確認を実施しました。M/T/Rv2の219依存ファイルを照合し、既存版は変更していません。

指定先は `main_round/anonymization/team10/attack/attackR/Rv4/` です。

- `submission/F_mia.csv`：実team10の1,049候補と22対象。
- `submission/F_aia.csv`：22対象×326問、7,172回答。

リポジトリの既存Python環境を使います。新しいPCでは `main_round/attack/setup.ps1` を実行してください。再生成先は新しいフォルダーを指定します。

```powershell
./main_round/anonymization/team10/attack/attackR/Rv4/run.ps1 -OutputDirectory ./main_round/anonymization/team10/attack/attackR/Rv4/reproduced
```

新しい杉山問題での評価は `main_round/mock_test/sugiyama.ps1 -Plugin ./main_round/anonymization/team10/attack/attackR/Rv4/plugin.py` を使えます。`experiment.py` は既存のRv2評価世界を再利用する開発記録で、保存済み評価を上書きしません。再実行にはignoredの旧Rv2評価世界が必要です。

GitHubにはソース・提出CSV・検証記録を保存します。CodaBenchへの提出は行っていません。
