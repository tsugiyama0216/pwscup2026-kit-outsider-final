## 変更方法

公開検出器で希少と判定される**65行のBMI・TG・ALTだけ、計195セル**を調整しました。V4の年齢・検査値7列を公開A_bgの平均・標準偏差で標準化し、各対象行に近い公開レコード50件の距離加重平均を求めます。その値に35%だけ近づける補間です。Bの特定個人やMIAで成功した個人を指定していません。

希少検出境界を越える11行では補間率を縮め、検出希少65行という区分を保持しました。実際の補間率は約6.86〜35%、対象65行の平均は約33.05%です。対象の選択と補間計算はV4・公開A_bg・公開検出器だけで実行します。**候補の採点・選択には私的Bと既知の疑似集合を使います**。V4/V3の来歴も含め、差分プライバシー保証はありません。

通常984行は文字列表現まで不変です。全行のtime・onset・death、およびBMI・TG・ALT以外の列も不変です。BMIの変更範囲は−1.580〜+1.063、TGは−23.087〜+12.741、ALTは−4.689〜+3.884でした。

## 別の攻撃と解釈上の限界

time・onset・deathも利用する追加の多視点MIAについても同じ9条件で確認しました。攻撃者平均の補正前TPR@FPR=0.01はV4が0.000000〜0.000000、V5が0.000000〜0.001923です。V5−V4の最大増加は0.001923でした。平均AUCはV4が0.491544〜0.512849、V5が0.491608〜0.512931です。**すべての攻撃で一律に改善したわけではありません。** この追加MIAは偶然補正・K正規化を行わない診断で、上のAnonへ合算していません。

8候補の選択に既知6seedを使ったため、その結果には選択による楽観性があります。新規3seedは未使用の疑似集合ですが、同じB/Aから再抽出しており独立データではありません。公開Aは補間先、背景KDE、対照nonmemberとして共用されています。公開Aへ寄せる方法はこの代理評価に有利な可能性があり、未知のnonmemberへの一般化を今回だけで保証できません。真の共有ブロック・他チームB_j・公式AIA対象も未入手です。

したがって、V5は**有用性を保ったまま、このDOMIAS代理評価で改善を確認できた候補**です。公式Anon、順位、差分プライバシー、未知攻撃への安全性を保証する結果ではありません。作成時点ではM1_v3を提出選択として保持し、2026-09-25のユーザー指定でV5へ変更しました。
