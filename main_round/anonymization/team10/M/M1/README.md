# M1：S1の公開参照ランク・コピュラ補正

作業者Mの本戦team10向け第1モデルです。S1の保存済みDP合成データを固定入力とし、S1で崩れた列間相関を公開 `A_bg.csv` の依存構造へ近づけました。S1およびS/R系列は変更していません。

## 方法

1. 公開A_bgから1,049行を固定seedで非復元抽出する。
2. S1の9共変量を列ごとに順位だけ並べ替え、公開行に近いSpearman依存構造を作る。この段階ではS1の各列の値と度数をそのまま保つ。
3. S1と同じ公開希少ドナー処理を再適用し、希少検出件数を公開率相当の66件へ整える。
4. S1と同じ公開Coxリスク最近傍により `time/onset/death` を一組で再割当する。

最終設定は相関補正強度1.0、seed `20260919`、死亡リスク重み0.31です。生成器はS1、公開A_bg、公開schema、S1設定だけを読み、`B.csv` と `B_self.csv` は読みません。ただし候補の選択には公式ローカル自己採点を使ったため、選択過程全体を事前固定された差分プライバシー機構とは主張しません。

## 攻撃耐性の追加評価

共通評価基盤の [M1耐性レポート](../evaluation/results/M1/SUMMARY.md) では、AIAの代理リスクは0.076456でしたが、運営DOMIASの希少側でMIA信号が出ました。偶然補正後のMIA βは0.164930、診断用耐性指数は0.835070です。K=12正規化は1へ飽和していますが、代理候補集合のmember構成が公式と異なるため、この値を公式Anonとは扱いません。

M1は有用性改善の基準として保持し、提出候補の確定前にMIA信号を下げた後継モデルと比較します。
