# M1_v4：M1_v3の有用性を改善した候補

**ローカル有用性Uは0.842644から0.874538へ改善（+0.031894）。参照DOMIASの入力・攻撃スコアはM1_v3と完全一致。** 2026-09-24の改善依頼に基づく別候補です。現在の最終提出選択はM1_v3のままです。

## 何を変えたか

M1_v3の有用性で最も低かったのは、Cox解析の係数・信頼区間に基づくU_specです。BMIが元Bでは有意、M1_v3では非有意となっていました。そこでR8で使用した集計Coxスコアの補正をM1_v3へ適用し、合成データ内の発症と打ち切りの組を交換しました。

変更は**4回の交換、8行・16セル、timeとonsetの2列のみ**です。年齢・性別・地域・検査値・喫煙・死亡フラグは各行で元の文字列表現まで保持しました。公開検出器の希少・通常区分内で交換しており、区分別の転帰タプル集合、発症人数、全体の発症曲線は保持されています。

元Bの個別行への最近傍合わせは追加していません。元BのCox係数・分散という集計値を使う私的データへの適合です。BMI係数はB=0.059503、v3=0.061871、v4=0.083346となり、有意判定は一致しましたが、BMI係数の点推定値そのものはBから離れています。全係数の信頼区間比較を含むU_spec全体が改善したという結果です。

## DOMIAS・追加MIAと総合代理スコア

固定版公式キットの参照DOMIASは連続7列だけを入力にします。この7列を同一行順・同一数値のまま保持したため、BとA_bgを合わせた6,192人の確信度はv3/v4で完全一致しました。前回保存されたv3の確信度も再現しています。検査列以外を利用する攻撃一般に対する同等性を意味するものではありません。

20疑似攻撃者の平均、20,000回の偶然補正、K=12は[前回の本戦形式比較](../evaluation/domias_main_round_20260924/README.md)と同じです。既知3seedに、候補選択前に決めた新規3seedを追加しました。同じ確信度・ラベルに対するDOMIAS結果は両モデルで共有できます。新規seedでは20,000回の置換を実行しました。

`Anon proxy = 1 − max(a_MIA, AIA proxy)`、`Objective proxy = min(U, Anon proxy)`。

| 候補集合seed | v3 Objective proxy | v4 Objective proxy |
|---|---:|---:|
| 20260924 | 0.597902 | 0.597902 |
| 20260925 | 0.650350 | 0.650350 |
| 20260926 | 0.842644 | 0.874538 |
| 20261001 | 0.842644 | 0.874538 |
| 20261002 | 0.842644 | 0.874538 |
| 20261003 | 0.737762 | 0.737762 |

**6条件中3条件で上昇、3条件で同点。最小値0.597902は変わりません。** 主seedのAnonは両モデル0.597902です。有用性が上がっても、DOMIAS側が制約になる条件の総合代理スコアは上がりません。

追加でtime・onset・deathを含む多視点最近傍MIAも比較しました。6条件すべてで補正前TPR@FPR=0.01の攻撃者平均は両モデル0でした。攻撃者平均AUCは両モデルおよそ0.491〜0.513で、v4−v3の最大絶対差は0.00025未満でした。この追加診断は偶然補正・K正規化を行っておらず、上表のAnonには含めていません。

新規seedは同じB/Aから取り直した候補集合であり、独立データのホールドアウトではありません。公開Aを対照と背景KDEの両方に用いる偏りや、真の共有ブロック・公式AIA対象がない制約は前回と同じです。公式得点・順位や未知の攻撃への改善は未確認です。

## 選択と検証の記録

事前固定した4設定（補正なしの目標係数、または有意係数の余裕2.0・2.1・2.25）を比較し、**Uが改善し、AIA代理リスクがv3以下**の条件から最大Uのguard225を選びました。guard210はU=0.874789でしたがAIA=0.083413へ増加したため不採用です。各設定の最大交換回数は24、採用候補は改善が止まった4回で終了しました。非有意係数の目標も既存R8の保護条件に従います。

候補決定後にCSVと選択記録を凍結し、追加確認の結果による再調整はしていません。候補選択は私的スコアを使うため、選択バイアスがあります。M1_v3の来歴も含め、差分プライバシー保証はありません。

3テストで、保存モデルからのバイト再現、静的11列の文字列不変、希少区分別の転帰集合保持、不正な入力や範囲外の変更の拒否を確認しました。初回実行ではAIA内訳の欠測NaNのJSON保存を修正しています。探索条件を変えず、修正前の条件も[保存](protocol_before_serialization_fix.json)しました。

```text

python -m unittest -v test_model.py
```
