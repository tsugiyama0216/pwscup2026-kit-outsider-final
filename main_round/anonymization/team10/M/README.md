### M1の概要

S1の固定DP合成データで崩れていた列間相関を、公開 `A_bg.csv` の順位依存構造を用いて補正しました。公開希少ドナー処理と公開Coxリスク最近傍による転帰割当を再適用しています。

- U_gen: 0.9214155715372894
- U_spec: 0.7521530456176521
- U_rare: 0.8183050847457627
- U_valid: 0.8727753152771738
- 1,049行×13列、希少検出66件、欠損・完全重複なし
- 同じ設定からのCSVバイト再現とハッシュ検証に成功

生成処理は保存済みS1と公開A_bg・schema・S1設定だけを読みます。候補選択には本戦のローカル自己採点を使用したため、選択過程全体を事前固定された差分プライバシー機構とは主張しません。公式結果は未評価です。攻撃耐性は、下記の共通基盤によるローカル代理評価を追加しました。
