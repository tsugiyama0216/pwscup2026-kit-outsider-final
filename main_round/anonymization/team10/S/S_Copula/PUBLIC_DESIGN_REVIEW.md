# 公開情報だけを使った設計レビュー

本レビューと設定選択では、本戦の公開背景データ `participant_data/A_bg.csv`、公開 `schema.json`、公式採点コード・公開設定だけを使用した。`B`、`B_self`、`utility_ref` の値は読んでいない。以下の公開データ代理実験は、本戦データの有用性を保証するものではない。

## 有用性 0.9 を難しくする採点構造

公式コードの有用性は `min(U_gen, U_spec, U_rare, U_valid)` である。

- `U_gen` の順位相関は、36 組の Spearman 相関の平均絶対差が 0.04 以下、90% 分位点が 0.08 以下でなければ 0.9 に達しない。周辺分布だけを合わせても十分ではない。
- `U_spec` は 9 個の Cox 係数について、有意・非有意の判定が異なる係数の寄与を 0 とする。1 個だけ不一致でも上限は `8/9 = 0.8889` になる。すべての有意判定が一致したうえで、信頼区間の重なりも高い必要がある。
- `U_rare` は希少率、臨床変数の周辺分布、発症率、Random Forest による同時分布の二標本分類の最小値である。ガウシアン・コピュラは裾の依存構造を取り逃がすことがある。希少人数だけの補正では解決しない。
- `U_valid` では行政的打切り時刻、打切り率、群間関係の強さ、重複、背景データを再掲していないことが評価される。

本戦公開背景データは 5,143 行だった。公開データから 1,049 行ずつを重複なしで 2 組抽出する実験を、固定乱数で 8 回行ったところ、実データ同士でも `U_spec` は 0.418–0.642、各組で 1–4 係数の有意判定が異なった。これは標本実現への忠実さを強く求める採点であり、同じ母分布を再現するだけでは 0.9 に届かないことを示す診断である。

## 採用した DP 設計の境界

本実装は、公開背景から依存構造を学び、非公開データから群別ヒストグラムを DP 化して得る、公開情報を併用する Gaussian copula 方式である。原論文 DPCopula の全アルゴリズムをそのまま再現したものではない。

固定された公開定義による `希少判定 × 性別 × 喫煙 × イベント種別` の 24 群を使う。1 人を置換して群が変わっても、群全体を連結した 1 ヒストグラムの L1 感度は 2。データ依存の閾値、経験分位点、相関、最小値・最大値を無雑音で非公開データから得ない。

予算は各 ε の 4/5 を copula、1/5 を Cox 補正に割り当てる。ε=1・3・10 の三つを公開する場合の保守的な逐次合成上限は ε=14、δ=0。これは今回の仕組みによるリリースについての保証であり、既存 R 系列の非 DP 出力、非公開データを直接使った採点表、将来の再計測まで自動的に包含するものではない。

整数ノイズは、L1 感度 Δ、割当予算 e に対し、有理数 `q=Δ/(Δ+e)` の幾何分布 2 個の差を使う。各座標の確率質量は定数倍の `q^|z|` なので、隣接入力間の尤度比は `exp(Δ log(1+e/Δ)) <= exp(e)`。有理数 Bernoulli を OS 乱数で実行し、逆 CDF の浮動小数計算、DP ノイズの固定シード、ノイズ支持の打切りを避けた。公開後の浮動小数変換では公知の飽和処理を行う。これは数理的な設計・コードレビューであり、第三者認証を受けたライブラリとの同等性を主張するものではない。

## Cox 補正と後処理

`dp_cox.py` は、背景データだけで Cox 係数、基準累積ハザード、標準化、情報行列を作る。非公開各行について、公知のモデルに対するスコア残差を計算し、固定の L1 球へクリップして整数に変換する。整数ベクトルは 10 次元、各行の L1 上限は 128、置換感度は 256。整数和に対する DP 計測は 1 回だけである。

雑音の大きい残差をそのまま反映すると低 ε で係数が不安定になったため、公開スコア共分散と幾何ノイズの既知の分散を使って公開 Cox モデルへ縮小する。非公開 Hessian・p 値・生の Cox 係数は使わない。この補正は一段階近似であり、正確な DP Cox 推定や係数の精度保証ではない。

合成データの Cox 調整は、保存済みの DP 係数だけを目標に、6 臨床変数の順位を入れ替える。各列の値の集合、年齢・性別・喫煙、イベント・観測時間を保つ。合成前後の Spearman 相関差を平均 0.02、90% 分位点 0.04 以下に制限する。候補選択に使うのは合成データと DP 目標だけであり、非公開データの採点結果ではない。

## 確認した実装特性

人工公開データを使う 4 テストで、整数 L1 上限と 1 行置換の感度、1 回だけの DP 計測、巨大な整数ノイズの安全な後処理、合成調整による周辺分布とイベントの保存を確認した。コピュラ本体のテストは別ファイルにある。テスト合格は DP の数学的証明や高得点の代わりにはならない。

非公開採点後に、その点数を見て設定や出力シードを選び直す行為はこのリリース方針に含めない。保存済み DP モデルのみを使う後処理は追加計測なしで実施できるが、その選択基準も公開情報または DP 出力に限定する。

## 公開代理実験の結果と限界

公開 5,143 行を固定の 1,049 行の代理対象と 4,094 行の学習背景に分け、ε ごとに 1 回の雑音付きモデルを生成した。周辺分布の公開事前分布の重さ、群人数への公開事前分布、公開半径分布への補正、Cox 後処理の有無を比較した。計 48 候補は公開データだけから得ており、非公開予算 ε=14 を消費する実験ではない。

| ε | 初期候補探索の最高代理 U | 主な律速項目 |
|---:|---:|---|
| 1 | 0.630850 | Cox 結果 |
| 3 | 0.576165 | Cox 結果 |
| 10 | 0.563575 | 裾を含む一般有用性・Cox 結果 |

記録は `public_proxy_tuning.json`。この実験は希少群の真値の代わりに公開検出器の判定を使い、KM 曲線の標本雑音床も 0 とした代理採点である。本戦の採点結果とは区別する。設定探索の合成シードは 98311、本番の固定後処理シードは 20260918 である。DP ノイズ自体のシードは固定していない。

別の雑音による設定固定後の確認では、代理 U は 0.589244 / 0 / 0.618512 となり、ε=3 の裾の不安定性が見つかった。公開データの値のないヒストグラム区間へのノイズと、半径補正による公開背景の支持範囲を越えた値が原因になり得る。実際、公開実験の FPG 最大値は 125.9997 だったのに、半径補正後の合成値は 135.68 に達した。FPG 上端の採点基準が厳しく、これが大きな失点につながる。初期の確認結果を `public_frozen_confirmation.json` に残している。

このため最終実装では、公開データの値のないビンの補間を最寄りの公開観測値に固定し、公開背景の各列の最小値・最大値を越える合成値を抑える処理を入れた。非公開データの実際の裾が公開背景の範囲を越えている場合は、その有用性を犠牲にする。この仕様は 3 予算すべてで事前固定した。変更後、別の雑音を使った公開確認は ε=1/3/10 の順に **0.298171 / 0.351409 / 0.666218** となった。記録は `public_tailguard_confirmation.json`。追加の点数選別や非公開入力による調整はしていない。

したがって、公開実験で目標 U=0.9 を達成したとは主張できない。ε ごとに異なる雑音実現を使っているため、ここでの得点が ε に単調でないこと自体は実装の DP 違反を意味しない。高得点の保証や、本戦データの希少群の評価に置き換えることもできない。
