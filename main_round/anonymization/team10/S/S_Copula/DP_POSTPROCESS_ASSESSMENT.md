# 保存済み DP 出力だけを使った追加改善可能性の確認

## 結論

**現在の Cox 後処理を長く回すだけで大きく改善する余地は小さい。** ε=1 と 3 は相関を守る制約の下で改善せず、ε=10 も保存済み DP 係数への誤差が約 5.9% 減るだけだった。特に低 ε の Cox 目標は公開事前モデルへの縮小が非常に強い。合成データをその目標へ完全に一致させても、非公開データの Cox 結果を正確に再現できるとは限らない。

これは有用性 U=0.9 が数学的に不可能だと示す結果ではない。他の後処理・最適化法の余地を尽くしたわけでもない。非公開データを見ずに言えるのは、**現行の後処理の反復数を増やすことについて、大きな得点改善を期待できる証拠がない**ということまでである。

## 使用した情報と変更範囲

使用したデータは `releases/eps1`、`eps3`、`eps10` の `model.json`、`C.csv`、`manifest.json` のみ。公開の事前モデルも各 DP モデルに保存されているものを使った。`B`、`B_self`、`utility_ref`、本戦の採点結果、`private_diagnostics` は参照していない。追加の DP 計測は行っておらず、消費済み予算は合計 ε=14 のままである。

保存済みモデルから初期合成データを再現し、同じ DP 目標・同じ相関制約・同じ学習率で、Cox 後処理を 16 回から 80 回に延長する候補をメモリ上だけで計算した。元のコード、固定設定、提出候補 C、モデル、マニフェストは変更していない。追加候補の CSV も保存していない。

## DP 目標への一致に残る誤差

係数は保存済み公開モデルの標準偏差で標準化し、9 係数の差の L2 ノルムを比較した。目的は合成データと **DP 目標** の一致であり、非公開の真の係数との一致ではない。

| 総 ε | Cox に使った ε | 現在の係数誤差 | 80 回反復後の係数誤差 | 改善率 | 現在の最大誤差 / C の標準誤差 |
|---:|---:|---:|---:|---:|---:|
| 1 | 0.2 | 0.341947 | 0.341947 | 0% | 1.711 |
| 3 | 0.6 | 0.308933 | 0.308933 | 0% | 1.358 |
| 10 | 2 | 0.192835 | 0.181426 | 5.9% | 1.071 |

3 ケースとも、DP 目標の全 9 係数は、現在の C から推定した Cox の 95% 信頼区間内にあった。この事実は非公開 B との有意判定一致や U_spec の得点を保証しない。

相関は最初の DP 合成データとの Spearman 相関差を使い、36 組の平均差 0.02 以下・90% 分位点 0.04 以下という固定制約を保った。

| 総 ε | 現在の相関差：平均 / 90% 分位 | 80 回後の相関差：平均 / 90% 分位 |
|---:|---:|---:|
| 1 | 0.009849 / 0.039066 | 同じ |
| 3 | 0.013276 / 0.036920 | 同じ |
| 10 | 0.011551 / 0.019654 | 0.013623 / 0.023121 |

ε=1・3 は制約内で採用できる候補が更新されなかった。ε=10 は制約にまだ余裕があるが、現行の順位入替え方式の改善は小さかった。

## DP 目標自体の不確かさ

整数スコアの 1 行 L1 上限は 128、置換感度 Δ は 256。Cox の割当予算を e とすると、各座標に加える整数ノイズの分散は次の式で正確に計算できる。

`Var(Z) = 2 Δ(Δ+e) / e²`

保存された公開クリップ幅は 11.221067、公開行数は 1,049。スコア平均の尺度に戻した DP ノイズの標準偏差は、ε=1/3/10 の順に **0.151336 / 0.050485 / 0.015187** だった。

実装はこのノイズをそのまま係数へ反映せず、公開共分散を使って縮小する。公開スコア平均の共分散を V、DP ノイズ分散を σ² とすると、縮小行列は `S = V(V+σ²I)⁻¹`。10 次元の平均縮小率 `trace(S)/10` は以下だった。

| 総 ε | 平均縮小率 | 公開モデルの仮定に基づく係数の残存不確かさ：標準偏差の L2 ノルム |
|---:|---:|---:|
| 1 | 0.004371 | 0.266935 |
| 3 | 0.036856 | 0.264139 |
| 10 | 0.258402 | 0.239945 |

低 ε では、雑音付き残差が示す方向への補正を強く抑え、目標係数の大部分を公開モデルで決めている。上表の平均縮小率は、この線形変換の性質を表す値であり、「非公開情報を何%知ったか」という尺度ではない。

最後の列は、公知の情報行列の逆を J とした `J[V−SV]Jᵀ` から計算した **近似的な事後共分散** である。公開データの共分散が対象集団にも当てはまるというモデル仮定に依存し、DP の精度保証・厳密な頻度論的信頼区間・非公開係数の実測誤差ではない。近似の範囲では、ε=10 の残存不確かさ 0.240 は、80 回反復後の合成対 DP 目標の誤差 0.181 より大きい。これ以上の目標への追従が、そのまま非公開データへの忠実さになるとは言えない。

## 実務上の判断

保存済み DP モデルだけを使う改善は、追加のプライバシー予算なしで可能である。ただし、今回確認した延長計算は追加の変更を正当化するほど大きな改善を示さなかった。ここで非公開の採点結果を選別基準として使ったり、より良い雑音を求めて再学習したりしてはいけない。新しい仕組みを検討する場合も、公開データ上で評価するか、保存済み DP 出力のみから選択基準を定義する必要がある。
