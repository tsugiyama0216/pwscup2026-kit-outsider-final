- `C.csv`：既存の合成データ（1,049行・13列）。元の保存ファイルとSHA256一致。
- `model.json`：このεの保存済みDPモデル。元の保存ファイルとSHA256一致。
- `manifest.json`：元の実行記録をバイト単位で保持。旧名称・元の保存場所への参照も履歴として保持している。
- `ORIGIN.json`：コピー元・ファイル照合記録。今回の追加計測は0。
- `PRIVACY_DESIGN.md`：機構、隣接関係、保証条件の説明。文書中の相対パスは元の実装場所を基準とする。
- `private_diagnostics/`：既存の非DPローカル評価。モデルのDP保証には含まれない。本説明の得点も非DP。

共通の実装と予算台帳は、隣の `../S_Copula/` に保持した。固定設定は `../S_Copula/frozen_config.json`、記録付き実行入口は `../S_Copula/release.py`。元の出力は `../S_Copula/releases/eps1/`。ファイルのコピー・改名で予算が復活することはなく、学習をやり直さない。

固定された公開背景・スキーマ、固定1,049行・1レコード置換隣接、適切な秘密乱数が保証の前提。公開相関を利用するGaussian copula変種であり、原論文DPCopulaの完全再現ではない。

今回の整理では新規計測・生成・採点を行っていない。ε1・3・10・20の4モデルをまとめた機構の基本合成上限は34。これら4出力の作成時点で、削除済みの旧ε400計測を含む使用履歴は434。その後2026-09-24に比較用ε15を1回追加し、最新のDPCopula計測履歴は449。非DP診断やR出力も含む資料全体のDP保証を主張するものではない。
