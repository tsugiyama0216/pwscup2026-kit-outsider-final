# 作業者Rの本戦攻撃

改善した杉山採点 [retest](../retest/README.md) の既定モデルは、凍結M v2のMIAと凍結T v88のAIAを組み合わせたR v1です。`sugiyama_adapter.py` は、retestの公開テーブルを既存のR v1関数へ渡します。攻撃アルゴリズム・学習済みモデル・選択値は変更していません。

今回のGitHub保存範囲はアダプターと、R v1の172件の依存照合に必要な6ソース・`dependencies.json` です。[依存ファイルの説明](v1/RETEST_DEPENDENCIES.md)を参照してください。実行入口は `../retest/run.ps1` で、R v1の提出CSV・提出ZIPはこの保存範囲に含みません。

固定M/T依存と公式ランタイムは同じリポジトリの既存配置を使います。`prepare_attack_m.ps1` がMのGit除外互換配置を準備します。攻撃には模擬世界の公開テーブルだけを渡し、隠れた正解・生成方式名・生成seedは渡しません。

公式コードでの模擬採点は本番の非公開正解・φ・実加工分布を再現せず、公式点の予測値ではありません。2026-10-07のユーザー依頼は既存非公開リポジトリのmainへのretest保存を許可するもので、公式提出は含みません。
