PWS Cup 2026 本戦・攻撃フェーズ 配布物

この zip には、加工フェーズに提出された全チームの匿名化データ C が入っています。

  C_<k>.csv             コホート k のチームが提出した匿名化データ（1,049行・13列）
  aia_challenge_<k>.csv コホート k に対する属性推論の対象行（326行）
  mia_columns.json      その回の攻撃対象コホートの一覧
  SHA256SUMS.txt        この zip に入っている各ファイルの SHA-256

自分のコホートも入っています（自分は攻撃しません。ルールブック §4）。
mia_columns.json に載っていないコホートには答える必要がありません。

■ 提出物が改変されていないことの確かめ方

大会 Web サイトと配布の通知メールに、同じ SHA-256 の一覧を載せています。
自分のコホート番号の行を、提出した C.csv のハッシュと突き合わせてください。

    shasum -a 256 C.csv        （Windows は certutil -hashfile C.csv SHA256）

この zip の中身をまとめて確かめるには、zip を展開したフォルダで

    shasum -a 256 -c SHA256SUMS.txt

■ 締切

攻撃提出の締切は日本時間の午前9時です。提出できるのは8回まで。
リーダーボードに載せた1件だけが順位の計算に使われます（ルールブック §5.3）。
