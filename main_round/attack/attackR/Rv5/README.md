# Rv5 — 公式フィードバックを起点とした保守的な追加攻撃

2026-10-09のユーザー依頼。保存先は `main_round/attack/attackR/Rv5/`。杉山採点、mock_TS、retest、それらの得点・順位・新しい30問題は、本版の設計選択・検証に使用していません。過去の採点器は変更しません。

## Rv2の弱点と対応

ユーザー提供の公式内訳は `official_feedback_Rv2_user_supplied.json` に原値を保存しました。

- 全体MIAは0.0744755、AUCは0.6213503。AUCが偶然以上でも、採点されるFPR 1%付近の順位が弱いことを示します。対象別の値は人数や点数ではなく帯です。22対象中20対象は第1帯であり、完全に攻撃不能という意味ではありません。
- 希少MIAは0.166667ですが、全体とは別のROCで採点されます。一部の少数例だけの改善を全体性能の保証にしません。
- AIAのmember成功率0.571668に対してcontrolも0.527050。当たりやすい時刻を一律に出すだけでは会員と対照の差が小さく、希少AIAも0.016104に留まっています。
- 現行Rv2の方式判定は模擬由来の固定分類器に依存します。新しい方式分類器への全面置換ではなく、実際の公開Cの一致証拠を追加します。番号9・11などを特別扱いする分岐はありません。

## 実装

**MIA:** Rv2提出CSVの確信度を基準とします。7数値属性と時刻を加えた8数値属性の2視点で、公開Cへの近さを背景への近さで補正します。性別・県の違いも距離へ反映し、両視点が支持する証拠を採用します。背景レコード自身の近傍は自身を除外して計算。背景の同性・同県（少数なら同性、全体へ後退）で上位1%相当の近さだけに、上限付きのlogit加算を行います。裏付けのない行は変えず、自己公開情報から厳密に分かる非共有163人は0を維持します。背景との出所差があるため、このtail値は本番FPRや所属確率を保証しません。

**AIA:** 公開7属性からCと背景の近傍を求め、±0.5年の窓に入る時刻の支持を比較します。唯一に近いCレコードの一致、または集中した時刻窓が背景との差でもRv2を十分上回る場合に限って置換します。遠い時刻同士の単純平均、無根拠な棄権の解除は行いません。既存予測のままの行も多くなります。Cが合成ならその時刻自体が真の時刻でない可能性は残ります。

`protocol.json` の数値は本番入力の変更件数を見る前に固定した設計値です。今回の公式点へ合わせて係数を最適化したものではありません。推論時にフィードバックJSONは読みません。

## 再現と提出

既存の `main_round/attack/.venv` を使います。初回PC設定は `main_round/attack/setup.ps1` を参照してください。

```powershell
./main_round/attack/attackR/Rv5/run.ps1 -OutputDirectory main_round/attack/attackR/Rv5/reproduced-01
```

このコマンドはCSVのみを生成し、既存出力を上書きしません。正本の提出ZIP生成は初回のみ `package.py` が行います。すでに提出先がある場合は拒否します。

- `submission/F_mia.csv`, `submission/F_aia.csv`: 本戦22対象の提出CSV。GitHub保存対象。
- `submission/team10_Rv5_attack.zip`: 上記2CSVと配布原本token.txtのみ。このPC限定、Git除外。
- `dependencies.json`: 本版コード、公式原本、Rv2基準CSV等の凍結ハッシュ。
- `production_diagnostics.json`: 対象別の変更件数と公開入力に基づく診断。
- `verification.json`: 独立2回の再現、公式ZIP・実配布ID・不正入力拒否の検証。
- `preservation.json`: 旧R版の不変性確認。モデル・過去の予測・提出ZIPは上書きしません。

初回生成ではMIAの84セルを変更し、18対象で計669か所の順位が変わりました。各対象の上位30人の集合はRv2と同じです。AIAは7,172行中15行を変更しました。これらは変更量であり、正解数や改善得点ではありません。数値処理7テスト・不正入力8種類の拒否、独立2回生成、公式ZIPと実ID検証が成功しています。

Rv5はRv2の保存済み予測を固定基準とする追加モデルです。Rv2全体の再学習・旧方式の再選択は行いません。新しいデータセットに流用するには、そのデータに対応する基準予測が必要です。依存ハッシュは別データへの誤適用を拒否します。

**本戦での得点改善は未測定です。** 公式集計だけから非公開の人物対応・加工方式・正解時刻は分からず、模擬採点を使わないこと自体も改善の証明ではありません。今回の確認は実装の正しさ・再現性・提出形式であり、本戦性能の検証とは区別します。CodaBench提出は実施しません。
