2026-10-09の依頼に基づくローカル候補です。**MIAはRv8方式、AIAはRv2を維持します。採用した数値アルゴリズムはRv8と同じで、Rv8をさらに上回る新方式ではありません。** 名前は依頼どおりRv12とし、今回比較した対照抑制案、不採用理由、新しい抽出での確認、再現用コードをこのフォルダーに保存します。

本番の隠し正解によるRv12の得点は未測定です。CodaBench提出、試行消費、GitHubへの送信、トークン入りZIPの作成は行いません。

## 参照した本番結果と他モデル

Rv2の利用者提供の本番攻撃力は **0.1966605682146923**、Rv1は0.169387840941965。差は全体MIAの改善で、AIAは同じです。Rv2のAIA標的正答率は0.5716675962074734、対照正答率は0.5270496374790853です。これらは対象平均であり、その平均を公式の対象別採点式に代入して総合点を復元できません。

既存の同条件評価ではRv8がRv2を上回り、Rv6・Rv7・Rv9・Rv10・Rv11、追加評価のMv1・Mv2・Rv3はいずれもRv2未満でした。予備戦の再評価もRv8を支持しました。ただし、予備戦結果と本戦模擬結果は別々の資料であり、平均合算しません。今回これらを参照したため、旧評価をRv12の独立検証とは呼びません。

出典の原値・SHA-256は [evidence/prior/](evidence/prior/) と [copied_evidence.json](evidence/copied_evidence.json) に保存しています。CodaBenchへ実際にアップロードされたファイルの同一性を運営側で独立照合したものではありません。

## 対照への正答を抑える案を採用しなかった理由

公式AIAは、概略として対象ごとの `(標的正答率 − 対照正答率)/(1 − 対照正答率)` を計算し、希少層の補正と対象別φ控除を行います。対照を外しても、標的の正答を多く失うと悪化します。

次の7候補を、全対象共通の条件で事前に宣言しました。採点器は変更していません。

- 背景でも当たりやすい時刻だけを控える4案。2種類の近傍で背景の時刻窓支持を確認し、Cの追加支持が乏しく、強い一致証拠がない行に限定。
- Rv2の固定済み標的・対照予測モデルを使い、対照への罰則を0.75／1／1.5へ上げる3案。元の0.5方式と対象全行が一致するcopy/independent分岐に限定し、既存時刻を11の棄権値にする変更だけを許可。厳密な公開属性一致は保護。

全7案が、既使用の2ケースの両方で**AIA単独の得点を悪化**させました。MIA改善を加えると合計が上がる案もありましたが、それをAIA改善の根拠にはしていません。例として弱い確率抑制案（0.75）は、2ケース合計で対照正答を204件減らす一方、標的正答も159件失い、補正済みAIAの平均を約0.009009低下させました。

[protocol.json](protocol.json) の採用条件に従い、全案を不採用にしてAIAを保持しました。[selection.json](selection.json) に全候補の原値、AIAだけの対象除外検査、選択時刻、固定ソースハッシュを記録しています。確認結果を見て設定を変更しません。

## 採用したMIA

Rv2の各相手に対する順位をロジットに変換し、その人物が相手全体で高く出やすい共通傾向（対象間中央値）を強度0.35で差し引きます。複数相手への同時所属を許し、所属人数や一人一対象という制約は設けません。自己公開情報の厳密一致から導ける非共有163人は、全22対象で0を保持します。

旧2ケースでの順位比較指標（全体MIA＋補正済みAIA）はRv2 **0.8861435991** → Rv12 **0.9048175178**、差 **+0.0186739187**。公式式の模擬合計は0.9796750676 → 0.9904818534、差+0.0108067858。これらは本番得点予測ではありません。
