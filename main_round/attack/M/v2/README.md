## v1からの変更

### AIA：県を使う条件を限定して緩める

採用方式は `guarded40`。通常はv1と同じ公式最近傍方式を使う。県・性別の一致候補が40行未満で、県を固定した最近傍距離が性別だけの最近傍距離の1.5倍を超える場合に、性別だけで照合する。候補が空の場合は公式と同様に条件を緩める。

距離は公開5数値属性（年齢・SBP・TG・HDL・ALT）の生値を背景の標本標準偏差でそろえる。同距離の最近傍が複数ならtimeを値順で並べて平均する。BMI・FPG・真の希少・標的/対照ラベルは入力に使わない。県が有効な相手まで無条件に取り除かない。

チーム番号で例外を指定せず、公開された候補数と距離で分岐する。C6・C8・C14の診断は候補を考える根拠にしたが、閾値は模擬開発評価の固定候補から選んだ。少人数ブロックや遠い近傍は、県の加工を証明するものではない。

### MIA：一般に高くなりやすい人の傾向を差し引く

検査値・弱い追加属性から作るv1の近傍密度比スコアを再利用する。各候補について22相手のスコア中央値を求め、各相手のスコアからその中央値を差し引く。選択強度は1.0。最後に相手ごとの平均順位へ変換し、厳密に導けた非共有163人を0にする。

この補正は「どこに対しても高く出る人」と「特定の相手にだけ強い証拠がある人」を区別するためのもの。排他的な共有構造を踏まえた補正だが、**1人を必ずどこかへ割り当てる処理ではない**。各相手25〜27人、真希少人数などの固定陽性枠は強制しない。提出値は所属確率ではなく順位スコアである。

非共有163人の導出は変更せず、[v1の本番用検査](../v1/actual.py)を使用する。人数・公開属性・ID・希少/発症構成の検査が崩れれば停止する。

## 選択と検証

MIAとAIAを別々に選択した。攻撃採点は両者を別評価するため、片方の改善で他方の悪化を隠さない。今回の二つの実験は条件分布が違うので、平均値を足して公式攻撃力の予測とはしない。

| 調整用 | v1 | v2選択候補 | 比較 |
|---|---:|---:|---|
| MIA | .753651 | .790153 | 18世界の主対象平均、16改善・2悪化 |
| AIA・φ未控除 | .289059 | .384099 | 主135条件、22改善・110同等・3悪化 |

AIAでは6候補を比較し、県を保持する条件の平均悪化を.005以内に制限した上で、主条件平均が最大の方式を選んだ。`guarded40`と単純な`support40`の開発平均差は.000431と小さく、距離ガードの優位を強く主張しない。最大の条件別悪化は−.165138で、全条件を改善する方式ではない。

MIAは強度0・.25・.5・1を比較し、世界ごとの主対象平均を等重みで平均して選択した。コピーと背景独立は選択から外した動作確認条件。非共有マスクはv1/v2双方に等しく与えた。18世界は3抽出×希少共有合計0/5/11×混合加工/弱ノイズの組で、候補者の共有先最大1、全29共有計736、非共有313、既知非共有163を再現した。

追加で、非候補ドナーの過剰な共有に対するストレス検査を行った。通常の模擬世界では少ない原本から非候補を再利用しており、相手同士の共通人数が実仕様より大きい。このため、候補以外を相手ごとに独立合成した6世界・132対象で、固定した強度1と基準0を比較した。MIA平均は **.605344→.631722（+.026378）**、5世界改善・1世界悪化、最悪の世界平均差は−.033491だった。全体TPRも.559069→.595176へ改善した。追加の強度探索には使わず、最終確認とは別の開発中の頑健性検査として記録した。

### 方式固定後の確認

全体の選択と依存ファイルを固定してから、別の抽出で採用方式とv1だけを比較した。確認後のパラメータ変更は行っていない。

MIAは18世界・396対象条件を評価し、コピー・背景独立を除く主対象を各世界で平均した。混合加工の9世界は各17対象、弱ノイズの9世界は各22対象で、世界を等重みにして集計した。主351対象条件では173改善・169同等・9悪化、最悪差は−.080000。世界平均の最小改善は+.013672だった。18世界は3抽出×3希少構成×2配置であり、独立した18人物群ではない。

希少側を最大値に採ることによる平均上積みは.042609→.041071で、全体としての改善は希少側だけによるものではない。ただし、強ノイズでは全体TPRが微減し、コピュラの改善には希少側の最大値が大きく寄与する。世界平均の全改善は、個別対象の全改善を意味しない。

AIAは189条件中、コピー・背景独立を除く135条件を主比較とした。県を背景比率に再割当した45条件で平均.114762→.400255。県を保持する45条件、県の人数を保ってシャッフルする45条件では、v1と完全に同じ予測だった。悪化2条件は強ノイズとコピュラで、最悪差は−.103408。県の人数を保った加工にも有効だとは主張しない。背景独立の動作確認でも正の代理値は出ており、局所的な改善を真の情報漏えいと断定しない。

## 限界と得点の意味

- 公式の相手別正解・φ・他攻撃者の結果は未公開。このローカル結果から相手の匿名性や総合点の低下を確定できない。
- 相手の総合点は有用性と匿名性の最小。攻撃は自分の有用性を改善せず、自分の総合点への直接加点でもない。相手の匿名性を十分下げられれば順位に効き得る。
- 模擬元人物はA_bg、独立背景は自Bで、本番と役割が逆。希少は公開検出器の代理であり真のis_rareではない。
- 調整用と確認用の人物群は非交差だが、その人物分割自体は過去の研究で使用済み。新seedは完全に未知の人物による検証ではない。
- MIAの通常世界は非候補の再利用が多く、追加の独立合成世界は相手間の非候補共有が0。どちらも実際の全コホートを完全再現したものではない。
- AIAの県集中は元人物に一貫した県の写像を適用して作った反実仮想。実際の生成法ではない。加工方式の割合も実22相手の割合を推定したものではない。
- 上位候補の重複減少、最近傍距離の短縮、予測時刻の変更件数は、正解率向上の証拠と区別する。

## 再現

既存の本戦Python環境を使い、リポジトリのルートから実行する。選択済みコードでの予測再現は次のとおり。空の出力先を指定し、以前の予測を保持する。

```powershell
./main_round/attack/attack.ps1 M-v2-test
./main_round/attack/attack.ps1 M-v2-predict -OutputDirectory main_round/attack/M/local-output/v2/recheck-predictions
```

調整の記録を上書きして再選択する入口ではない。`M-v2-aia-evaluate` / `M-v2-mia-evaluate` は `-Stage holdout -OutputDirectory <空のM/local-output/v2配下>` で固定候補の確認を再現できる。同じ確認を繰り返しても独立の評価が増えるわけではない。

新しい調整は別版に保存する。`M-v2-freeze`は調整完了後・確認開始前に一度だけ選択を固定し、`M-v2-complete`は両確認の完了を登録する。生成器は選択・依存コード・確認記録が一致しなければ停止する。

配布原本・公式キット・提出済みC10は変更していない。CodaBenchへの提出、試行の消費、提出ZIP作成は行っていない。v2のコード・本番予測CSV・評価記録を上記の非公開GitHub保存対象とし、別の追加研究はこの保存に含めない。
