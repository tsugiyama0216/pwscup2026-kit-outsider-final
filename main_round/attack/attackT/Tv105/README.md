2026-10-08、ユーザー指定により **pl2をTv105へ改名**しました。アルゴリズム・予測CSV・得点は同一です。凍結ソース、selection.json、過去の採点記録と模擬出力の内部ID `pl2` は再現性のため保持しています。現在の表示名はTv105、正本はこのフォルダーです。旧PCフォルダーpl2はWindowsの改名拒否により互換用として残っています。

2026-10-08作成。4候補を比較し、調整用mockTSでMIA混合18候補とAIA合議4候補から構成を固定。その後の確認用mockTSでは選び直していません。

MIAは **Tv101 × 0.5 + Tv104 × 0.5** の順位混合です。AIAは4モデルの予測時刻について±0.5年窓の支持を比べ、**Tv101** の票を2倍にします。単独モデルの改名ではなく、新しい組合せです。

## 候補

- Tv101：公開背景から方式判定器を学習し直す。生成方式を丸ごと除外する診断を含む。T88の攻撃専門部品は固定。
- Tv102：T88の判定確信度が0.60未満または上位差0.15未満なら不明とし、公式参照へ切替・混合。
- Tv103：性別・県・年齢を合わせたC/背景の5近傍密度比を、T88のMIA順位へ25%混合。
- Tv104：Tv101の判定器、未知対応、背景補正を組み合わせる。画像の4項目目は評価手順なので、この統合候補と固定後確認に対応させた。

## 実行

本戦用環境は `main_round/attack/setup.ps1` で構築します。全モデルは保存済みTの学習資産に依存します。新しく学習するのは方式判定器のみで、完全なfresh-background-only評価ではありません。

```powershell
./main_round/attack/attackT/Tv105/run.ps1 -Phase development
./main_round/attack/attackT/Tv105/run.ps1 -Phase confirmation
```

計算済み条件は再利用します。元の記録を上書きする調整はしません。mockTSの単独実行には `Tv105/plugin.py`、各候補には `../Tv101/plugin.py` 等を指定できます。大きな問題・正解・予測はignoredの `main_round/mock_test/local-output/mock_TS/pl2_20261008/` にあります。

本番22対象のCSV作成（確認試験後、新しいTv105内の出力先を指定）：

```powershell
./main_round/attack/attackT/Tv105/production/run.ps1 -OutputDirectory ./main_round/attack/attackT/Tv105/reproduced
```

本番では自己公開情報から証明できる非共有163人を0にします。mockTSにはその自己情報がないためマスクを適用しません。ZIP・トークンコピー・CodaBench提出は行いません。Tv105の公式得点は未測定です。
