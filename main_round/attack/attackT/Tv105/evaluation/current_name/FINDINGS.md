# Tv101〜Tv104とTv105の解釈

固定後確認は12加工データ×3問題、36条件です。Tv105はRv2・Rv4に対して平均+0.021367521、11勝18同点7敗でした。Tv101に対しては平均−0.001068376、5勝25同点6敗で、全候補の最良ではありません。確認結果を見た再選択は行っていません。

改善はMIAによるものです。確認平均はRv2の0.011752137に対してTv105は0.033119658、AIA平均はともに0.023626231です。小さい希少層の成功・失敗が集計値を大きく変えるため、単一条件や3抽出の結果を安定した本番優位とは解釈しません。

## 4案の結果

- **Tv101：方式判定器の再学習**は確認平均0.057814265で今回最高。公開背景から作った7方式の診断と、保存済み12加工Cへの実際の攻撃を分けて記録しました。平均攻撃点の改善は、実際の生成方式を正しく特定できた証明ではありません。
- **Tv102：不明時の代替攻撃**は0.027192826でRv2より悪化。疑わしい判定を見つけることと、切替先が強いことは別でした。今回の固定された代替ルールは支持されませんでした。
- **Tv103：層別背景補正**は0.035378367でRv2と同点。調整用では小幅改善しましたが、確認用の平均改善はありませんでした。
- **Tv104：判定器・不明対応・背景補正の統合**は0.038927485。MIAは上がりましたがAIAが下がり、Tv101を下回りました。

Tv105は4候補をそのまま改名せず、MIAの順位混合18候補と、4出力の時刻窓合議4候補を調整用で比較しました。Tv101/Tv104の50:50順位混合とTv101重視のAIA合議を固定し、確認用では平均0.056745889になりました。正確な原値は各CSV・JSONを優先してください。

## 合成方式の特定に関する限界

元のT88判定器は単純な7方式・63模擬Cで正解率88.89%。Tv101の調整側同条件診断は平均90.48%で、生成方式を丸ごと除外した場合の不明判定率は92.06%でした。一方、実際の12加工CへのTv101の不明判定率は調整・確認とも100%です。判定器が学習した単純7方式で、複合的な実加工を説明し切れていません。

例えばR1は文書上、層別ガウシアン・コピュラの完全合成です。しかし元のT88は今回の問題でindependentと推定しました。R5は逐次CART合成で、そもそも7分類の中に対応する専用クラスがありません。R3/R4/R6以降やM1_v5には後処理が重なるため、これらへ単一の正解ラベルを割り当てた分類正解率は計算していません。`release_family_notes.json` と `routing_diagnostics.csv` を参照してください。

背景から生成する方式判定器だけが今回の公開入力で新しく学習されます。T88の攻撃専門モデルには既存の学習履歴が残ります。新しいseedでも同じ有限人物集団・保存Cの再利用であり、完全な未知集団による独立検証ではありません。mockTSの合成対照・代理希少ラベルにも依存します。公式点・本番順位の予測ではありません。
