生成された問題・採点用の行単位の正解・回答CSV・攻撃ログは、元の `main_round/mock_test/local-output/` に保存したままです。このフォルダーには比較・検証用の記録を収録しています。別PCでは [再実行手順](../README.md) に従って回答と疑似問題を再生成できます。

JSON内の絶対パスは評価時のPCを示す履歴情報です。コピー元の記録を保持するため変更していません。再実行コードはリポジトリ内の相対配置から入力を解決します。GitHubではMarkdown・CSV・JSONを直接参照でき、HTMLはダウンロードしてブラウザーで開けます。

本戦の模擬φは背景からの1,000回抽出で推定した値です。実際の非公開φではなく、得点も本戦公式得点の予測値ではありません。
