## 変更点

本戦版PDFと9月9日の事務局メールの要約です。詳細な定数・境界条件は原本PDFと9月12日配布予定の設定ファイルを参照してください。

| 項目 | 予備戦から本戦への変更 | PDF |
|---|---|---|
| U_gen | marginal・pMSE・time_dzの最小から、corr・tailを加えた5指標の最小へ | §6.1.1、pp.14–16 |
| 相関 corr | 主要9列・36組のSpearman相関差を平均と上位側で評価 | pp.14–15 |
| 裾 tail | 検査値6列の上下の極端な分位点と、複数列をまとめた外れ度を評価 | pp.15–16 |
| U_valid | mean(cens, no_fab)からmean(cens, no_fab, no_dup, novel)へ | §6.1.4、pp.17–18 |
| 重複 no_dup | record_idを除く完全重複行の割合を減点 | p.18 |
| 新規性 novel | A_bgへの最近傍距離の分布を比較し、公開行に近すぎるCを減点 | p.18 |
| 打ち切り cens | 定義と実装の食い違いを修正。行単位の整合と打ち切り率の一致の弱い方。非発症・非死亡の行がない場合、行単位の整合は0点 | p.18 |
| AIAの匿名性側 | 最大の攻撃失点を選んだ後、コホート別水準φ_iを1回控除し0〜1に制限 | §6.2.2、p.21 |
| AIAの攻撃力側 | 各攻撃者・標的の組でφ_iを控除し0〜1に制限した後、標的平均。MIA力への追加控除はなし | §6.3、p.22 |
| 自己攻撃 | 自己のMIA列・AIA行があっても受理し、採点では除外することを明文化 | §6.3、p.22 |
| 自己採点の環境差 | Uで0.001未満という説明を、同じCでもU_rareが0.01程度動く場合があるという説明に訂正 | §5.4、p.11 |

Uを4観点の最小値でまとめること、総合得点をmin(U, Anon)とすること、予備戦0.1・本戦0.9の重みは維持されています。攻撃力は総合得点とは別に扱います。

**本戦の新指標は予備戦の得点・順位に遡及適用されません。** 自己列の不具合訂正による予備戦の攻撃力変更とは別件です。[予備戦の確定結果と訂正一覧](../../prelim/results/20260909/README.md)に区別して記録しています。
