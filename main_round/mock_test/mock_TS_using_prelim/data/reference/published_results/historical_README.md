## 匿名化から得た示唆

**有用性を犠牲にする加工を採用するなら、その損失に見合う匿名性の改善を、加工前後の比較で確認する。** 今回の「くぼみ」は、4つの有用性指標のうちU_specが突出して低い形を指します。データ分布の一部を削ったという意味ではありません。この節は公開結果からのチーム内の考察であり、事務局による評価コメントではありません。

### 公開結果から分かること

- team24の匿名性は0.4223で21チーム中17位、有用性は0.5336で20位でした。順位は総括の採点値がある21チームを各指標の降順で数えたものです。有用性が低い一方、匿名性も上位水準には達していません。
- U_specの低さは、指定された解析の結論・予測性能を再現しきれなかったことを示します。その低さだけから、個人情報を強く守れたとは判断できません。
- team24を標的とするMIA明細では、全候補でのTPR（FPR=0.01）は20攻撃者中16者が0、20者の平均は約0.01311でした。一方、希少なメンバーを含む6者中4者では希少側のTPRが正で、全体・希少の大きい方を採る集計値の平均は0.12725でした。希少側での検出がMIA失点を押し上げています。この0.12725は偶然水準の控除・正規化前の値です。
- 最終的に、MIA成分0.5777が匿名性0.4223を決め、総合得点も0.4223となりました。広い範囲での検出を抑えられた面と、少数の希少な人への耐性が不足した面を分けて捉えます。TPRが0だったことは、あらゆる攻撃に対する安全の証明ではありません。

根拠：[原本Excel](sources/公開用結果表_20260909.xlsx)の「総括」と、「攻撃_標的別_MIA」の標的24の20行。MIA成分は「総括」K21、匿名性はM21です。

### くぼみの効果について、まだ判断できないこと

U_specが低い形の方式でも、それに見合う匿名性を得られれば有効な場合があります。**くぼみがある方式を一律に否定する根拠はありません。** また、公開結果は提出版1件の評価であり、加工前後に同じ攻撃を適用した比較は今回の確認では行っていません。したがって、この加工で匿名性がどれだけ改善したか、あるいは改善しなかったかという因果効果は確定できません。

総合得点はmin(U, Anon)なので、現在のAnon=0.4223を固定してU_specだけを改善しても、総合得点は変わりません。一方、匿名性だけを改善しても、現在のU=0.5336が総合得点の上限になります。**U_specの回復と、希少群へのMIA耐性の改善を両方確認する必要があります。**

### 今後の比較で残す記録

1. 加工前後を同じ評価データ・同じ攻撃・同じ採点規則で比較し、加工以外の条件をそろえる。
2. Uの4指標、匿名性のMIA・AIA成分、総合得点min(U, Anon)を並べ、何を失い、どれだけ守れるようになったかを記録する。
3. 全体の平均に加えて希少側の検出と人数を確認する。公開正解で調整した結果と、調整に使わない評価データでの結果を区別する。

これは今後の検証方針です。比較実験をすでに実施したという記録ではなく、本戦では本戦版の採点規則で確認します。

## 本戦ルールと次の配布

**本戦版main-process-20260912は公開済みです。** [更新確認・変更点一覧](../../../main_round/rulebook/README.md)と[保存した公式PDF](../../../main_round/rulebook/PWS_Cup2026_ルールブック_main-process-20260912.pdf)を参照してください。予備戦当時のルールブックは上書きしていません。

本戦の加工フェーズは **2026-09-12 09:00 JST** 開始予定。メールではB・B_self・A_bg、採点イメージ、参照データ、自己採点キット、自チームのAIA控除水準が同時に配布されると案内されています。9月9日の確認時点では本戦版GitHub Releaseはありません。PDFの更新と実装・配布物の更新を区別してください。
