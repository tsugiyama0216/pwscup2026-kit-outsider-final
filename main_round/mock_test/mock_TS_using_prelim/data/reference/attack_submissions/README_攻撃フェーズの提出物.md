# PWS Cup 2026 予備戦 攻撃フェーズの提出物

2026年9月9日公開。

## 中身

予備戦・攻撃フェーズについて、**各チームがリーダーボードに掲載した1件**の提出物です
（ルールブック §7.2）。21チームぶんで **21件**あります。
ファイル名はコホート番号です（`cohort01_F.zip` 〜 `cohort29_F.zip`）。
コホート番号とチーム名の対応は、同時に公開する採点結果表の総括シートにあります。

各 zip の中身は `F_mia.csv` と `F_aia.csv` の2つです。

## 事務局が手を加えたところ

- **ファイル名をコホート番号に付け替えました。**元のファイル名は各チームが付けたものです。
- **`token.txt` を除きました。**各チームの認証情報のためです。
- 再圧縮したので `__MACOSX/` などの付随物も落ちています。
- **`F_mia.csv` と `F_aia.csv` の中身は変えていません**（1件ずつ照合しています）。

## 自分のコホートの列が入ったままの提出物があります

`cohort01`・`cohort10`・`cohort17`・`cohort18`・`cohort20` の `F_mia.csv` は21列で、
自分のコホートの列を含んだままです。**提出されたとおりの姿でお出ししています。**
採点では自分のコホートは対象外です（同時にお送りするお知らせの「攻撃力の訂正について」をご覧ください）。
