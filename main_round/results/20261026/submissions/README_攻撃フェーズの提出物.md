# PWS Cup 2026 本戦 攻撃フェーズの提出物

2026年10月26日公開。

## 中身

本戦・攻撃フェーズについて、**各チームがリーダーボードに掲載した1件**の提出物です
（ルールブック §7.2）。23チームぶんで **23件**あります。
ファイル名はコホート番号です（`cohort00_F.zip` 〜 `cohort28_F.zip`）。
コホート番号とチーム名の対応は、同時に公開する採点結果表の総括シートにあります。

各 zip の中身は `F_mia.csv` と `F_aia.csv` の2つです。

## 事務局が手を加えたところ

- **ファイル名をコホート番号に付け替えました。**元のファイル名は各チームが付けたものです。
- **`token.txt` を除きました。**各チームの認証情報のためです。
- 再圧縮したので `__MACOSX/` などの付随物も落ちています。
- **`F_mia.csv` と `F_aia.csv` の中身は変えていません**（1件ずつ照合しています）。

## 自分のコホートの列が入ったままの提出物があります

`cohort00`、`cohort03`、`cohort05`、`cohort07`、`cohort11`、`cohort16`、`cohort25` の `F_mia.csv` は自分のコホートの列を含んだままです。**提出されたとおりの姿でお出ししています。**
採点では自分のコホートの列は除いています（ルールブック §6.3）。
