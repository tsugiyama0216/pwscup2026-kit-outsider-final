## アウトサイダーの成績

本戦はコホート10、予備戦はコホート24です。最終得点は、総合得点・攻撃力のそれぞれについて **予備戦×0.1＋本戦×0.9** で求められます。

| 区分 | 総合得点 | 総合順位 | 攻撃力 | 攻撃順位 |
|---|---:|---:|---:|---:|
| 本戦 | 0.5561677379859198 | 15 | 0.1966605682146923 | 18 |
| 最終（予備戦・本戦の加重得点） | 0.5427816039179676 | 15 | 0.2110613258545454 | 16 |

出典は公式Excelの「総括」A12:S12、「最終得点」A16:O16です。「最終得点」L16の本戦攻撃力は `0.1966605682146922` で、「総括」R12とは `1e-16` の差があります。原本とCSVでは両方をそのまま残しています。

| 本戦の内訳 | 公式掲載値 |
|---|---:|
| 有用性 U | 0.8745376811 |
| 一般有用性 U_gen | 0.9200261447 |
| 特定有用性 U_spec | 0.9280276668 |
| 希少有用性 U_rare | 0.9669160992 |
| 妥当性 U_valid | 0.8745376811 |
| 匿名性 Anon | 0.5561677379859198 |
| MIA成分（守る側の失点） | 0.4438322620140802 |
| AIA成分（守る側の失点、φ控除後） | 0.1865960531052816 |

本戦の総合得点は `min(U, Anon)` なので、この提出版の得点を決めたのは匿名性です。匿名性は `1 − max(MIA成分, AIA成分)` で、MIA成分が大きい側でした。これは公開結果の読み取りであり、加工方法の変更による効果を測った比較実験ではありません。

## 原本と展開データ

- `sources/`：公式Excel、公開ZIP2点、出典ページのHTML。受信したバイト列のまま保存しています。
- `truth/`：正解ZIPから展開した48ファイル。23コホート分の `pool_ids_<k>.csv` と `aia_truth_<k>.csv`、`aia_floor.csv`、公式READMEです。
- `submissions/`：23チーム×2ファイルの予測CSVと公式README。内側のZIPの原本は、`sources/`の提出物ZIPに含まれています。
- `tables/`：Excel全9シートのCSVと、表内の計算・掲載順位の照合記録です。CSVは値の閲覧用です。書式・注釈はExcel原本で確認してください。
- `verification/`：公開予測と正解に公式の攻撃採点処理を適用した検証記録です。
- [archive_inventory.csv](archive_inventory.csv)：外側ZIP・内側ZIPの118項目と、展開先・サイズ・SHA-256の対応表です。

本戦の匿名化データCとAIA challengeは、既存の[攻撃配布物ZIP](../../attack/downloads/PWSCup2026_final_attack.zip)と[展開済みデータ](../../attack/targets/)を参照します。配布ZIPのSHA-256は公式ページ記載の `bdab1804efd39e6e227220ede168d2031fe1275b1b46655ef7891116a3160dc3` と一致しました。

公式の提出物READMEによると、事務局がファイル名をコホート番号に変更し、認証用の `token.txt` と付随ファイルを除いて再圧縮しています。CSVの内容は変更されていません。今回の保存対象は、この公開済みの資料です。

`cohort00`・`03`・`05`・`07`・`11`・`16`・`25` のMIA予測は自分のコホートの列を含みます。公式公開物をそのまま保存し、採点時に自己標的を除外します。自己列が残っていることをデータ破損として扱いません。

## 確認した内容

- ZIPの破損検査、23コホートの一致、正解・予測の件数、展開前後のバイト一致。
- 公式Excelに記載された攻撃CSV46件、匿名化C23件、対象一覧 `mia_columns.json` のSHA-256一致。
- 全9シートの全セルがCSVに保存されていること、23チームの加重得点・掲載順位・得点構成が表内で整合すること。
- 公開された攻撃予測を公式 `score_attack` で再採点し、23チームの攻撃力とMIA・AIAそれぞれ506件の標的別明細が、原本Excelと許容差 `1e-12` 以内で一致すること。

再採点は **FPR=0.01、時間の許容誤差±0.5年、希少群の係数1.64、公開された標的別φ** を使っています。守る側のMIA偶然水準・匿名性の集計処理と有用性は再実行していません。これらは公式表の掲載値を保存し、表内の計算を照合しています。過去の模擬評価や試作版の値とは分けて扱います。

保存内容は次のコマンドで検証できます（リポジトリのルートから、Python 3の標準ライブラリで実行）。

```powershell
python main_round/results/20261026/verify_archive.py
```

展開し直す場合は `prepare_archive.py`、CSVを取り出し直す場合は `tables/extract_tables.py` を使います。マニフェストの更新用 `--write-manifest` は、保存内容をレビューして更新するときだけ使います。

今回保存した公開正解を使って今後モデルを調整する場合、その評価は大会後の再評価です。大会時点の提出版の公式成績とは区別して記録してください。
