# PWS Cup 2026 本戦 正解データ

2026年10月26日公開。本戦・攻撃フェーズの答え合わせに使う正解です。
ここにあるファイルは、事務局が公式記録を出したときに使ったものと同じです。

## 中身

| ファイル | 中身 |
|---|---|
| `pool_ids_<k>.csv` | コホート $k$ に配った候補 1,049 人ぶんの表。`record_id` は配布した候補の行番号、`pool_id` は母集団の中でその人を指す番号、`is_rare` は希少かどうか |
| `aia_truth_<k>.csv` | `aia_challenge_<k>.csv` の各行について、伏せていた `time`（追跡年数）と `onset`（発症の有無）、`label`（`member`＝標的／`control`＝対照）、`is_rare` |
| `aia_floor.csv` | コホートごとの、AIA で差し引く水準（ルールブック §6.2.2 の $\phi$）。`team_id` がコホート番号。標的の23コホートぶん |

コホート番号とチーム名の対応は、同時に公開する採点結果表の総括シートにあります。
23コホートすべてが匿名化データ $C$ を提出したので、`pool_ids_` と `aia_truth_` はどちらも23コホートぶんあります。

## MIA の答え合わせのしかた

あなたが提出した `F_mia.csv` の `record_id` は、あなたのコホートに配られた候補の行番号です。

1. 自分のコホートの `pool_ids_<自分>.csv` で、`record_id` を `pool_id` に読み替える。
2. 標的 $k$ の `pool_ids_<k>.csv` に載っている `pool_id` の集合を作る。
3. 1 で読み替えた `pool_id` がその集合に入っていれば、その人は標的の元データ $B_k$ に
   含まれていた人（メンバー）です。

希少な候補だけに絞った読み取り（ルールブック §6.2.1 の手順2）には、
自分のコホートの `pool_ids_<自分>.csv` の `is_rare` を使います。

## AIA の答え合わせのしかた

`aia_truth_<k>.csv` の `challenge_row_id` は `aia_challenge_<k>.csv` の行番号です。
提出した `time_hat` が `time` と ±0.5 年以内なら正解です（ルールブック §6.2.2）。
`label` が `member` の行が標的、`control` の行が対照です。

## AIA で差し引く水準（aia_floor.csv）

本戦では、コホート $k$ への攻撃の $R$ から、そのコホートの水準 $\phi_k$ を差し引いています
（9月9日のお知らせ「あなたのデータを使わなくても当たる分の差し引き」）。
採点結果表の 攻撃_標的別_AIA シートの $R$ と、総括シートの「AIA（φ を引く前）」は差し引く前の値です。
総括シートの「AIA 成分」は、攻撃者ごとの失点の最大値から $\phi_k$ を引いて 0 と 1 のあいだに収めた値で、
Anon はこれと MIA 成分のうち悪いほう（$1-\max$）です。
各チームには 9月12日に自分のコホートの値をお知らせしましたが、ここでは全コホートぶんを載せています。
